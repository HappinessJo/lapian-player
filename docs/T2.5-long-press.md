# T2.5 长按连发验证记录

- **日期**：2026-10-19
- **任务**：[tasks.md](../tasks.md) M2 / T2.5
- **状态**：自管 300ms 首延迟 + 70ms 连发、忽略 OS 重复、焦点丢失停止、边界 clamp 完成；2s 帧数/每帧呈现待正式计时。
- **范围**：PgUp/PgDn/左右长按；不接音频、时间轴拖动。

## 1. 实现

- `GfxWidget` 自管 `QTimer`：
  - 按下 PageUp/Left 或 PageDown/Right：先立即 step 一次，再 `start(300)`；
  - 第一次 timeout 后改 70ms 间隔（≈14.3Hz），忽略 `isAutoRepeat()` 的 OS 重复；
  - 松开/焦点丢失停止定时器并清方向；
  - 每 tick 发 `stepRequested(±1)`，MainWindow 同步走 `GoToFrame`。
- 步进使用 T2.4 的 `MediaSession::SeekToFrame` + `PlaybackController::SetPosition`；每帧都 seek 并呈现。
- 边界：`GoToFrame` clamp 到首/末帧；继续按住不越界。
- QAction `上一帧/下一帧` 不设快捷键，避免和 GfxWidget 双触发；只保留动作入口。

## 2. 验证

- 合成 PageDown 按下并保持 1.2s：V9 从第 0 帧到 **第 14 帧**（1 + 300ms 后约 13 次 70ms tick）。
- 按 2s 线性外推约 **25 帧**，高于 F3-A3 的 2s ≥20 帧；正式 2s 计时/录屏仍待 T7。
- 每帧都走 `SetVideoFrame`；帧号连续（每次 +1），画面/信息栏同步。
- 松开后定时器停止；再按不会残留上次方向。

## 3. 待补
