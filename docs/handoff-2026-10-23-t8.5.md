## 2. 接口（给 T8.6 / T8.7 / T8.8）

```cpp
namespace lapian::online {

// 纯解析 + 一次 GET；不下载。
QString BuildPlayUrlUrl(const QString& bvid, qint64 cid, int qn = 64);
BiliResolveError ParsePlayUrlJson(const QByteArray& json, PlayUrlData* out);
PlayUrlFetchResult FetchPlayUrl(IHttpClient*, const QString& bvid, qint64 cid,
                                int qn, const PlayUrlFetchOptions&,
                                const HttpCancelToken&);

// 下载计划（T8.6 从 PlayUrlData 构造）
struct DownloadPlan {
  QStringList urls;          // 主 + backup_url
  qint64 total_bytes = 0;    // 必须 >0
  qint64 length_ms = 0;
  int qn = 0; int codecid = 7;
  QString format;
  CacheMetadata metadata;
};

class DownloadJob {
 public:
  DownloadJob(CacheStore*, CacheKey, std::shared_ptr<GrowingSource>,
              IDownloadTransport*, DownloadPlan,
              DownloadRefreshCallback refresh = {}, DownloadOptions = {});
  bool Start(QString* error);     // Reserve/OpenPart/打开写句柄/起线程
  void Pause(); void Resume(); void Cancel(); bool Wait(int timeout_ms = -1);
  DownloadState state() const; DownloadStats stats() const;
  QString part_path() const; CacheKey key() const;
};
}
```

语义/约束（给 T8.6）：

- **Start 前**：调用方创建 `GrowingSource(total)`；`total` 必须等于 plan.total，且 `>0`；`.part` 已有字节由 Job 在 Start 中 `Publish(existing)`。
- **首帧**：等待 `source->Published() >= 0.3MB` 后 `GrowingFormat::Open`；T8.5 实测 open 8–9ms、首帧 10–14ms。
- **暂停**：Pause 会中断当前 HTTP（≤100ms 级），保留 `.part`；Resume 从 `.part` 长度续传。
- **取消**：Cancel 只置位/中断，不 join；`Wait()` 等线程结束。`.part` 保留、`source->Cancel()`（读层 AVERROR_EXIT）。
- **完成**：Job 先关闭写句柄，再 `MarkComplete`（rename 到 `.mp4`）。**T8.6 必须在完成前 `Cancel`+join 所有 reader**；reader 句柄不带 DELETE，否则 rename 会 busy 失败（T8.4 约定）。
- **已完整缓存**：Start 返回 `stats.already_complete=true`、state=completed，不下载；T8.7 应先用 `OpenComplete` 走本地路径，不调用 Job/playurl。
- **失败**：`source->Fail(EIO/ENOSPC/...)`；`.part` 保留；`stats.error` 可直接展示（不含 URL/Cookie）。
- **锁顺序**：`OnlineSession → CacheStore → GrowingSource`；Job 不持有 CacheStore 锁等 reader。

## 4. 关键决定与解释

1. **`quality` 只信服务端返回**：请求 qn 只是输入；OB-2 请求 64/80/112 都是 16，如实记录 360P。`--online-fetch-test` 对 qn<64 返回 `blocked`（退出码 2），不是 pass。
2. **下载 transport 与 `IHttpClient` 分开**：媒体 GET 需要流式写/取消/Content-Range，且绝不能带 Cookie；复用 `IHttpClient` 会把 JSON body 全读进内存且语义不清。`WinHttpApi.h` 只共享动态加载器。
3. **200@offset>0 不读 body**：transport 在 headers 阶段直接返回 `range_ignored`，Job 决定 truncate/覆盖；避免“读到一半再丢弃”或把全量 append 到旧字节后。
4. **truncate vs 原地覆盖**：没有 reader 时 truncate 从 0 重下（DoD 口径）；已有 reader 时原地覆盖，避免读层把突然变短的文件映射成 EIO。两种都记录 `range_ignored_truncated/overwrote`。
5. **重试分类**：403/404/410/400 等硬失败直接切备份/刷新；网络/超时/5xx 同 URL 退避 300ms/1s/2s，最多 3 次；任何有新字节的失败都从新长度续传（不重下整文件），总失败次数有上限。
6. **刷新只一次**：3 个 URL 都失败后刷新 playurl 一次；刷新后总大小必须与原 total 一致，否则失败保留 `.part`，不拼接。
7. **写盘后 Publish**：`WriteFile` 成功 → `written_` 更新 → `source->Publish(written_)`；每次写后 `GetFileSizeEx` 对账，Published 不超前文件长度。
8. **完成顺序**：close 写句柄 → `Publish(total)` → `UpdateProgress(force)` → `MarkComplete` → `OpenComplete` 验证；rename 失败保留 `.part` 并 `Fail(EIO)`。
9. **暂停用“取消当前尝试”实现**：Pause 取消 token，transport ≤20ms 轮询退出；Job 保持 `.part`/写句柄，Resume 从当前长度再发 Range。Cancel 同路径但终态。
10. **探针在 QApplication 之前分流**：`--online-fetch-test` 无 GUI；离线默认不联网；`--real` 才建 HTTP。

## 6. T8.6 / T8.7 / T8.2.2 需要什么

### T8.6（在线会话/UI，直接消费者）

- 用 `PlayUrlData` 构造 `DownloadPlan`；`CacheKey = {bvid,cid,data.quality,data.codecid}`；`CacheMetadata` 写 title/owner/duration/宽高/fps（T8.6 从 view/meta 补齐）。
- 确认后：`GrowingSource(total)` → `DownloadJob` → 等 `Published()>=0.3MB` → `GrowingFormat`/`MediaSession` 首帧；默认停第 0 帧、不自动播放。
- 取消/换 seek：按 generation `job.Cancel()`/`source.Cancel()`，等待旧 reader `<100ms` 退出；不要用旧帧覆盖新目标。
- 完成前：`Cancel`+join reader，再让 Job `MarkComplete`；否则 `.part` rename busy。
- 暂停/缓冲：UI 显示 `DownloadJob::state()` + `stats()`（Published/Size、bps、TTFB、range/backup/refresh）；未缓存 seek 不承诺 80ms。
- 失败：`stats.error`/`DownloadState` 映射 delta §5；已缓存区仍可播；不显示签名 URL/Cookie。
- 缓存命中：先 `OpenComplete` + `Touch`，不调用 view/playurl（T8.7 验收 0 请求）。

### T8.7（缓存命中/记录）

- `complete=true` 时 `OpenComplete` 直接本地打开；`DownloadJob::Start` 的 `already_complete` 只是兜底，不应成为主路径。
- 在线记录/截图目录/`index.jsonl` 独立于缓存根；清缓存不删记录。
- 标记/截图记录 qn/codecid/fps；换档位按 bvid+cid 保留。

### T8.2.2（扫码，非门）

- 与 T8.5 无关；按计划在 T8.5 之后做；T8.5 未改 `OnlineResolveDialog`/`IHttpClient` 的语义（只抽了 WinHTTP 加载器）。
- 若 T8.2.2 要读 `Set-Cookie`，需要扩展 `IHttpClient`/`WinHttpClient` 的响应头能力；T8.5 的下载 transport 不需要改。
