## 2. 线程/生命周期

1. **何时建**：`OnScrubStarted`（增长会话）或拖动中索引首次就绪时
   `EnsureOnlinePreviewStarted`；只在稳定索引 `IsReady() && !empty()` 且
   `online_stable_frames_ > 0` 时创建。没有索引时只显示等待，不创建空转线程。
2. **读层**：预览线程内 `GrowingFormat::Open(source, .part)` + 独立
   `VideoDecoder::OpenWithFormat(..., prefer_hardware=false)`；只读视频 source，
   不读音频。`MainWindow` 不持有 `GrowingFormat`/`FFmpeg` 上下文。
3. **目标合并**：`UpdateTarget(frame, cached)` 只改 latest target + generation；
   `TakeLatestFrame` 丢弃“比当前目标更靠后”的帧和反向拖动的非目标帧；正向拖动
   连续发布中间帧，反向只发布目标帧（与本地 T2.9.1 语义一致）。
4. **索引快照**：拖动开始时拷贝稳定 `FrameIndex`；索引继续增长时仅当目标超出
   快照或增长 >30 帧才在 GUI 线程再拷贝一次；worker 只持 shared_ptr。
5. **结束**：`EndScrubPreview` 停 16ms timer，`OnlinePreviewDecoder::End` 设置
   cursor interrupt、join 预览线程、释放 latest/24 帧缓存/sws；随后
   `GoToFrame(target)` 走既有精确 seek。关窗 `ShutdownOnlineSession` 先
   `online_->Cancel()` 唤醒 reader，再 `StopPreview()`，最后才 finalize。
6. **有界性**：一个预览线程、一个在途解码、latest 1 帧、cache ≤24 帧；
   没有每目标新线程，没有 UI 线程 join 网络等待。`End` 实测 3.18ms（单测），
   探针松手 release 3–39ms；关窗 9–76ms。

## 4. 缺口/残余风险

1. **反向预览帧率不承诺**：24 帧 cache 用完后按关键帧重解，DASH 反向仅
   10 presented/s；本任务不把反向写成 ≥30fps。
2. **未缓存区不承诺帧率/P7/P9**：只做提示/等待/取消/不冻结；未缓存目标不做
   预览 seek。
3. **真 4K/1080P60 未测**：样本 DASH 1080P30；4K/60 仍属 T8.15/T7.4，不写可用。
4. **软件解码/编码覆盖**：预览用软解+swscale；HEVC/AV1 高码率/弱 CPU 未测吞吐；
   预览帧是降采样，不是精确帧。
5. **切档中拖动未测**：`ShutdownOnlineSession`/切档路径会 `StopPreview`，但探针
   未在拖动中触发清晰度切档。
6. **在线旋转样本未单测**：tick 使用 `session_->info().rotation`，与本地同一
   来源；没有专门在线旋转素材。
7. **UI gap 只测事件循环**：不测渲染掉帧/GPU。
8. **P1/P2 首轮热缓存噪声**：首轮 p50 漂移 +11.76%/+13.15%（exit 3），复跑 final dist
   **PASS exit 0、0 超差**；不写“零退化”，以复跑为准。
9. **T8.14 残余风险保留**：未定位 teardown `0xC0000374`、L-1 seed 卡住；不写
   “无崩溃/已证明稳定”。
10. **T8.15 未执行**：当前默认凭据 `vip_status=1` 使 M2 普通用户前置失败；
    这不等于大会员验收通过，T8.15 仍“未执行/未验证”。
