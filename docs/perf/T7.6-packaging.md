## 3. 每用户安装（不要求管理员）

- `PrivilegesRequired=lowest`；默认目录
  `{localappdata}\Programs\拉片软件`；开始菜单组 `拉片软件`；桌面快捷方式
  由默认勾选任务创建。
- 静默安装（从 C: 本地目录运行，见 §8 的 E: 限制）：

```powershell
& "$env:TEMP\t76\Lapian-0.1.0-setup.exe" /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /SP- /LOG=...
```

- Inno 安装日志：`User privileges: None`、`Administrative install mode: No`、
  `Install mode root key: HKEY_CURRENT_USER`、`Installation process succeeded`，
  退出码 **0**。
- 安装后目录含 `lapian.exe`、Qt/FFmpeg/VC DLL、`platforms\qwindows.dll`、
  `imageformats\`、`styles\`、`README.txt`、`licenses\`（5 个文件）。
- 快捷方式：桌面 `拉片软件.lnk`、开始菜单
  `拉片软件\拉片软件.lnk` / `第三方许可与源码说明.lnk` / `卸载 拉片软件.lnk`。
- 开源码用户数据被 Windows 安全策略拦下的问题见 §8；不是安装脚本本身的问题：
  同一 setup 从 C: 运行即可创建目录、写注册表与快捷方式。

## 4. ProgID 与文件关联（不强制默认）

注册表（全部在 `HKCU`，随用户卸载清理）：

| 位置 | 内容 |
|---|---|
| `Software\Classes\Lapian.Video` | 默认值 `拉片视频`；`DefaultIcon` 指向 `{app}\lapian.exe,0` |
| `...\Lapian.Video\shell\open\command` | `"{app}\lapian.exe" --file "%1"` |
| `Software\Classes\Applications\lapian.exe` | `ApplicationName=拉片软件`、`ApplicationVersion=0.1.0`、`FriendlyAppName=拉片软件` |
| `...\Applications\lapian.exe\shell\open\command` | 同上 |
| `...\Applications\lapian.exe\SupportedTypes` | `.mp4`、`.mov`、`.mkv`、`.webm`（空 REG_SZ） |
| `Software\Classes\.mp4` 等四个扩展名的 `OpenWithProgids` | `Lapian.Video`（空 REG_SZ） |

- **没有写扩展名默认值**：安装前后 `HKCU\Software\Classes\.mp4` 等默认值均为空；
  `UserChoice` 保持系统原有 AppX（Films & TV / Media Player），未被改动。
- 用 `ShellExecuteEx` + `SEE_MASK_CLASSNAME`、`lpClass="Lapian.Video"` 实测
  ProgID 启动（不修改默认应用）：

```
shell_execute=True
pid=...  window_ms=359  title='拉片软件'
command="C:\Users\...\AppData\Local\Programs\拉片软件\lapian.exe" --file "E:\...\proxy-V1.mp4"
```

- 结论：关联命令、含空格/中文路径与 `--file` 传参可用；“打开方式”候选通过
  `OpenWithProgids` + `Applications\lapian.exe` 注册。**Explorer 真双击/用户在
  “打开方式”里选择**未自动化，留 T7.7 手测。

## 7. 零网络请求（运行/安装/卸载）

- 静态：`scripts/check-imports.ps1` 对 stage 的 20 个 exe/dll 断言无
  `QtNetwork.dll`、`tls/`、`networkinformation/`、`winhttp/wininet/urlmon`；
  仅 `Qt6Core.dll -> WS2_32`（Qt 固定链接，已知接受）。
- 动态：以 100–200ms 轮询 `Get-NetTCPConnection` + `Get-NetUDPEndpoint`
  （按 PID）：

| 阶段 | 观测到的 TCP/UDP 连接 |
|---|---:|
| 安装（setup 进程） | 0 |
| 安装后启动 ×3 | 0 |
| 安装后 `--robust-test` | 0 |
| ProgID 关联启动 | 0 |
| 卸载（unins000） | 0 |
| 便携 zip 启动 | 0 |

- 局限：没有管理员级 ProcMon/防火墙抓包；轮询可能漏掉极短连接。结论是
  “未观测到网络请求 + 静态导入断言”，不是抓包级证明。
- Inno 脚本本身没有任何下载/更新逻辑；安装/卸载为离线。

## 8. 卸载清理与用户数据边界

静默卸载（`unins000.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART`）退出码 0：

| 检查项 | 结果 |
|---|---|
| `%LOCALAPPDATA%\Programs\拉片软件` | 已删除 |
| 桌面 `拉片软件.lnk` | 已删除 |
| 开始菜单 `拉片软件\` | 已删除 |
| `HKCU\Software\Classes\Lapian.Video` | 已删除（含 shell/DefaultIcon） |
| `HKCU\Software\Classes\Applications\lapian.exe` | 已删除 |
| 我们的 `.mp4/.mov/.mkv/.webm\OpenWithProgids` 值 | 已删除 |
| 其它应用的 OpenWithProgids 值 | **保留**（实测每项 4–5 个，前后一致） |
| 卸载注册表项 | 已删除 |
| `%APPDATA%\拉片软件\settings.json` | **保留**（哈希不变） |
| `%APPDATA%\拉片软件\marks\` | **保留**（哨兵文件哈希不变） |
| 视频旁 sidecar | **保留**（`proxy-V1.mp4.lapian.json` 哈希不变） |
| 扩展名默认应用 `UserChoice` | 未改动（仍为 AppX） |

- `.mp4` 等 `OpenWithProgids` 键在卸载后仍存在，是因为键里本来就有 B 站/AppX
  等其它应用的关联值；Inno 的 `uninsdeletekeyifempty` 只在键为空时删键，
  这里正确地保留了共享键。**不是我们的残留**。
- 用户数据边界：安装器只管理 `{app}`、开始菜单/桌面快捷方式与 `HKCU` 下
  自己创建的 ProgID/Applications/OpenWithProgids 值；不写
  `%APPDATA%\拉片软件`，不碰视频旁 sidecar 与 `snapshots\`。

## 10. 环境异常与限制（必须如实记录）

1. **E: 工作区被 Windows 视为不受信任位置。** 从 `E:\拉片软件开发\out\package`
   直接运行 setup 时，进程被套受限 token：
   - Inno 报 `Setup was unable to create the directory ...\Temp\is-*.tmp`（Error 5）；
   - 预建目录后报 `CreateFile failed; code 5`（无法写 `unins000.dat`）；
   - 同样的 exe 复制到 `C:\Users\...\AppData\Local\Temp\t76\` 后安装成功。
   - 最小对照：自编译的 `writeprobe.exe` 在 E: 写 AppData 失败，复制到 C: 成功；
     Explorer 对 E: 上的 setup 弹出“打开文件 - 安全警告”。
   - 结论：这是本机对 E: 的执行/写入限制，不是安装脚本缺陷；真实用户从
     `Downloads`（C:）双击不会遇到。**测试与复现时先把 setup 复制到 C: 再运行。**
2. **F1-A1 未做正式验收**：热缓存、非基线机、未用 Explorer 真双击；只做了
   `--startup-test` 与 ProgID 启动预检。正式数字需要 T7.7 冷缓存/基线机/真双击。
3. **安装器 UI 英文**：Inno 6.7.3 自带语言不含简体中文；未引入第三方翻译文件。
   功能、许可、卸载不受影响；如需中文向导，另立任务。
4. **未签名、无自定义图标**：setup 与 `lapian.exe` 均未签名（无代码签名证书）；
   `lapian.exe` 无图标资源，快捷方式显示默认图标。杀软误报风险未验证。
5. **未测**：安装时 app 正在运行（`CloseApplications` 分支）、覆盖安装跨版本、
   降级、无重启、管理员/全机安装、Windows 10 21H2 实机。
6. **Inno Setup 许可提示**：6.7.3 编译器横幅提示商业用户购买许可证；
   `license.txt` 允许商业使用但请求商业用户购买。若本项目为商业分发，
   需评估购买 Inno Setup 商业许可（不随包分发编译器，不影响用户安装）。
7. **T7.3/T7.4/T7.5 结论不变**：V10 2h/P14 未通过；4K 仍只是 proxy；
   可达 SMB/物理设备丢失/真实 V8 未验。
