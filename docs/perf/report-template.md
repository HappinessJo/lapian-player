# 性能测量报告模板

> 用于 T0.2 起的测量记录与 T7.x 验收报告。复制本文件到 `docs/perf/T<任务号>-<主题>.md` 填写。

## 1. 元信息

| 项 | 值 |
|---|---|
| 任务 | 例：T2.9 拖动预览 |
| 日期 | yyyy-mm-dd |
| 机器 | CPU / 内存 / 显卡 / 磁盘 / 系统版本；是否 spec §4.1 基线机 |
| 素材 | V1–V10 中实际使用的编号与文件（代理素材必须标注） |
| 代码版本 | git commit（`git rev-parse --short HEAD`） |
| 测量脚本 | `scripts\measure\...` 与参数 |

## 2. 测量条件

- 冷/热：是否清理 OS 文件缓存、是否重启、是否首次启动；
- 次数与统计：每项 20 次，p95 = 至少 19 次达标；同时给 p50；
- 干扰：后台进程、电源模式、VSync、显示器刷新率；
- 4K：是否硬解、是否降采样预览。
