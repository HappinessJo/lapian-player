# T6.4 DPI/布局测量记录

- **日期**：2026-10-20
- **范围**：spec §4.3 — 1920×1080 在 100%/150%/200% 缩放下主要控件不裁切、不重叠；tasks.md T6.4
- **机器**：开发机 Windows 11 x64 / RTX 4060 / 1920×1080 @100% 物理缩放；**不是** 4C/8G/集显基线机
- **DPI 方式**：`QT_SCALE_FACTOR=1 / 1.25 / 1.5 / 2` 启动进程，Qt 逻辑坐标按比例缩放；**不是**改 Windows 显示设置，也不是多显示器/每屏 DPI 验收
- **代码**：T6.4 代码提交 `8de14cd`
- **单测**：`ctest` **18/18**（约 10.36s；T6.4 没有新增 ctest 项，布局走 `--dpi-test` 集成验证）
- **分发**：`dist` **32.34MB / 25 文件**（P12 上限内）
- **自动化入口**：`--dpi-test --dpi-expect-scale <1|1.25|1.5|2> --dpi-tag <名>`（需 `--file`）

## 1. 改动摘要

| 改动 | 目的 |
|---|---|
| 初始窗口按 `QScreen::availableGeometry()` 收缩，100% 仍 1280×720；150% 1248×624；200% 928×452 | 1080p@150/200% 时窗口 frame 不超出屏幕 |
| 侧栏宽度 240–300（窗口宽 ×0.26，clamp） | 200% 时给画面/信息栏让出约 60px |
| InfoBar 宽/窄两套网格（`<760` 逻辑像素换行） | 200% 下格式/总帧移到第二行，不裁切不重叠 |
| 文件名 `elidedText` + tooltip | 长文件名不推高最小宽度 |
| GfxWidget 最小尺寸 480×270 → 320×180 | 200% 下窗口最小高度回到可用区内 |
| 状态栏 Qt/FFmpeg 版本标签在 `<1000` 隐藏 | 次要信息让位，避免状态栏撑宽；音量/音频/循环/波形保留 |

时间轴/波形仍用逻辑像素绘制；Qt 负责按 DPR 生成物理像素，T6.4 没有改时间轴帧映射或 8px/帧上限。

## 6. 结论与不宣称

1. **1920×1080 的 100%/125%/150%/200% 布局在 `QT_SCALE_FACTOR` 模拟下通过**：正常窗口、
   全屏、820 宽窄窗口都没有裁切/重叠；200% 的 InfoBar 自动换成两行。
2. **T6.1 全屏回归在高 DPI 下恢复通过**：窗口初始尺寸不再超出屏幕，150%/200% 的
   全屏 `gfx-grew`、38 项检查均通过。
3. **不是真实显示缩放/多显示器验收**：`QT_SCALE_FACTOR` 只验证 Qt 逻辑坐标与布局；
   Windows 显示设置 150%/200%、每屏 DPI、RDP、4K 显示器仍需 T6.4 手测/T7.7。
4. **不是真人字体/IME 验收**：中文文件名省略是程序化断言；不同系统字体、输入法候选框
   在 150%/200% 下的位置未测。
5. **状态栏版本标签在 <1000 逻辑宽度隐藏**是有意取舍；音频/循环/波形/音量/帧号仍保留。
   若以后认为版本信息必须常显，需要重新分配状态栏空间。
