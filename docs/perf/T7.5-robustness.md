## 3. 方法

### 3.1 产品入口 + 测试探针

`--robust-test`（`src/app/RobustTestRunner.cpp`）在真实窗口里按顺序调用产品
入口 `MainWindow::OpenFile` / `GoToFrame` / `AddMark` / `CaptureSnapshot`，
只读 ForTest 状态；不绕过 `ShowOpenError`、MarkStore、SnapshotService。

- 每个错误用例记录 `OpenFile` 墙钟耗时；断言 ≤5s、旧会话/旧帧保留、
  `kind=error` 横幅可见、错误文本含预期关键词。
- 模态错误框由 25ms 定时器自动 `done(Cancel)`，防止探针被人机对话框挂住；
  探针记录 `modal_dismissed=10`。
- 设备丢失：`StartPlayback` → `SimulateAudioDeviceLossForTest(true)` →
  等 `AudioState=silent` → 700ms 后检查帧号前进 → 清除模拟 → 等恢复 playing。
- 只读目录：`scripts\robust-readonly.ps1` 用 `icacls /deny <user>:(W)` 设置
  ACL，验证目录确实不可写后启动 `--robust-only readonly`，`finally` 里
  `icacls /remove:d` 恢复；视频放在 `--robust-root` **之外**，避免探针清理根目录。
- 长路径：8 段中文目录 + `测试视频_长路径.mp4`，路径 288 字符；同一轮里打开、
  跳帧、加标记（sidecar 必须留在原地）、截图（`snapshots/`）。

### 3.2 新增产品改动（只做 T7.5 需要的）

1. **网络路径有界预检**（`media/PathProbe.{h,cpp}`）：UNC/映射盘识别 +
   `GetFileAttributesW` 工作线程 + 3s 等待上限；失败时保留旧会话、直接给可读
   错误，不进入 `avformat_open_input`。修复前断网 UNC 打开实测 21s。
2. **本地可读性预检**（`OpenFile`）：存在但打不开（独占/ACL）时给出“被占用/
   权限不足”，不再误报“文件不存在”。
3. **路径原生分隔符**（`OpenFile`）：Qt 对话框给正斜杠路径；正斜杠 + 不存在
   文件会被 FFmpeg 当 URL，报 `Illegal byte sequence`。现在统一转
   `QDir::toNativeSeparators` 后再探测/解码/建索引。
4. **目录打开**：`QFileInfo::isDir()` 直接提示“这是文件夹”，不再借 FFmpeg 的
   权限/不存在错误。
5. **长路径 sidecar**（`MarkStore::WriteAtomically`）：`ReplaceFileW` /
   `MoveFileExW` 不会自动加 `\\?\` 前缀；>MAX_PATH 时 Qt 临时文件能写，
   Win32 替换失败会误回退 AppData。现在显式转 `\\?\C:\...` /
   `\\?\UNC\server\share\...`。
6. **设备丢失模拟**（`AudioEngine::SimulateDeviceLossForTest`）：只加测试开关，
   复用 `HandleDeviceLost`（silent + 时钟失效 + 2s 重试），不改产品默认路径。
7. **错误详情/独立 AppData**（`MainWindow` ForTest）：`LastOpenErrorForTest`、
   `LastNavigationErrorForTest`、`SetMarkAppDataRootForTest`，避免测试写真实
   `%APPDATA%`。

## 9. 网络盘

| 场景 | 结果 |
|---|---|
| 不可达 UNC（`\\203.0.113.x\...\missing.mp4`，每轮换末位避免 SMB 负缓存） | **3,031.5 / 3,036.1ms** 返回“网络路径在 3s 内无响应，已取消打开” |
| 可达主机、共享不存在（`\\127.0.0.1\lapian-t7.5-missing\...`） | 20.9 / 22.0ms，“没有读取权限/被独占” |
| 修复前同一台不可达主机 | `lapian_media_probe` **21,053.9ms**；属性查询 **21,034.4ms** |

- 预检是**同步等待最多 3s**：UI 会短暂阻塞（<5s 规则），不是完全异步打开；
  可访问但读写很慢的网络盘仍可能在后续探测/解码阻塞（已知缺口）。
- **可达 SMB 共享上的成功打开、sidecar 写、截图未验证**：本机非管理员，
  无法创建共享；`\\localhost\E$` 的 FFmpeg 打开返回 permission denied。
  这一项留给有共享/管理员权限的环境或 T7.7。

## 11. 不宣称 / 缺口

- **不是 V8 正式素材**：V8 是“损坏或不支持的文件”类别，本文用合成 7 类覆盖；
  没有用真实下载损坏片做人工验收。
- **不是物理设备丢失**：模拟同一状态机；USB 拔出、驱动禁用、设备恢复后的
  听感/时长仍需真人。
- **网络盘成功路径未测**：只测不可达与共享不存在；可达共享的读/写/延迟、
  sidecar 合并、截图都未验证。
- **只读目录是 ACL 模拟**：脚本即时设置/恢复；未测真实用户长期只读目录、
  网络只读共享、ACL 继承差异。
- **没有磁盘满/IO 错误注入**：sidecar 双写失败由 T5.1 单测覆盖；截图写入
  失败由 T5.4 的目录回退覆盖；真实磁盘错误未做。
- **没有崩溃恢复测试**：原子写语义由 T5.1 单测覆盖，未在写盘中途强杀进程。
- **没有冷缓存/基线机**：所有耗时是开发机热缓存。
- **UI 在网络预检时最多阻塞 3s**：满足 5s 上界，但不是完全异步；更大的
  打开线程化改动不在 T7.5 范围。
- **测试探针在发行二进制内**：与既有的 `--drag-test`/`--memory-test` 一致，
  不影响默认路径；后续若做 P12 再评估。
