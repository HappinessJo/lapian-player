- p95 = 同一操作 20 次，至少 19 次达标；P1/P2 同样按 20 次 p95。
- 基线机：4 核 CPU / 8GB 内存 / 集成显卡 / SATA SSD / Windows 11，关闭其他负载；
  保证档要求 D3D11 + 硬解可用。
- P6/P9 的 1080p 强数字以“目标帧距其前一个关键帧 ≤2s”为前提；长 GOP 样本
  单列，按可用档记录，不混入 80/150/200ms 判定。
- P7 = ±1 帧步进（热解码器、相邻帧）；另测跨 GOP 边界后退：2s GOP ≤80ms，
  未达标时收紧到 1s；4K ≤150ms。
- 4K 放宽档：P4 ≥20fps、P6 ≤300ms、P7 ≤150ms、P9 ≤300ms、P8 ≥12fps。
- P12 ≤100MB；P1 ≤1.5s、P2 ≤2.5s；P14 2h WS ≤1200MB、无持续增长、不崩溃/卡死。
- 每用户安装、无需管理员；运行期零网络请求；不修改源视频。
- **不要改 80/150/200/300/1200/100 等阈值来变绿；不要用 proxy 代替 V4，
  不要用合成 V10 代替正式 P14。**

## 8. 判定与报告模板

报告至少包含：

1. 机器指纹、OS/驱动、exe SHA-256、素材路径/大小/哈希、GOP 统计。
2. F1–F8 逐项 pass/fail/blocked，附证据路径；失败项写复现步骤。
3. P1–P14 表：n、p50、p95、max、over、阈值、分类（≤2s 或长 GOP）、结论。
4. P7 边界专项：2s/1s/1080p60 HEVC/长 GOP/4K 分列；2s 余量。
5. P10/P11/P14 内存：WS/private、句柄、线程、增长斜率、`pass/flags`。
6. 安装/关联/零网络/卸载/源文件哈希证据。
7. 明确写“通过/未通过/阻塞”，不要把预检、proxy、合成素材写成正式验收。
