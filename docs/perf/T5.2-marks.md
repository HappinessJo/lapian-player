## 2. 自动化序列

```powershell
$dir = Join-Path $PWD 'build\t5.2-marks-final'
New-Item -ItemType Directory -Path $dir -Force | Out-Null
Copy-Item '.\media\V9.mp4' (Join-Path $dir 'A.mp4') -Force
Copy-Item '.\media\V9.mp4' (Join-Path $dir 'B.mp4') -Force
.\dist\lapian.exe --file (Join-Path $dir 'A.mp4') `
  --file-b (Join-Path $dir 'B.mp4') --mark-test
```

序列：

1. 打开 A：0 标记、sidecar 不存在；
2. 逐帧 0–100 各按一次添加，共 **101** 个标记；sidecar 生成；
3. 重开 A：101 个标记、first=0/last=100；
4. 点击帧 100 标记：`playing=0`、`frame=100`；
5. 20 次点击（帧 0/5/…/95）测 UI 与画面精确耗时；
6. 删除帧 42 标记（101→100），重开仍为 100；
7. 切到 B（B 的 sidecar 预置损坏 JSON）：B 0 标记、1 条警告、`.bak` 生成；
8. 切回 A：A 仍为 100（F8-A3）；
9. 删除 A 的全部标记：100→0，sidecar 消失（F6-A6）；
10. 再打开 B：0 标记。


- 101 个标记添加/重开/列表显示正常；标签默认“帧 N”，备注为空（编辑在 T5.3）。
- 删除 42 后重开为 100，F6-A2 的持久化部分通过；**确认对话框本身未在自动化中点击**（见 §5）。
- 无标记时不产生 sidecar；删除最后一个标记后 sidecar 消失，F6-A6 的 UI 路径通过。
- B 的损坏 sidecar 被备份为 `.bak`，UI 警告 1 条；A 的 100 个标记在切换 B 后重新打开仍存在。

### 3.2 点击标记：UI 与画面

20 次点击（帧 0/5/…/95），`ui` 覆盖选中、播放头、帧号更新并立即 `repaint()`；`exact` 从点击开始到 `GoToFrame` 返回且 `current_frame_ == target`：

```text
T5.2 mark_perf ui_n=20 ui_p50=5.32 ui_p95=5.91 ui_max=5.91
                exact_n=20 exact_p50=17.11 exact_p95=31.34 exact_max=31.34
```

- **UI p95 5.91ms ≤100ms**（F6-A8 的 UI 数字），留有余量；
- **画面精确 p95 31.34ms ≤200ms**（1080p P9 数字）；
- 这是**热解码器 + V9 短 GOP** 的标记点击路径，不是 P9 的“冷随机 20 目标”。正式 P9/F6-A8 仍需 V1/基线机/4K 与冷启动测量，见 §5。
- 实现上先更新面板/播放头/帧号并强制重绘，再用 `QTimer::singleShot(0)` 执行精确 seek；因此长 GOP 下 UI 也不会被解码阻塞，但画面时间会落向可用档。

### 3.3 列表与时间轴微基准（离屏）

`lapian_mark_panel_test` / `lapian_timeline_test`：

```text

[perf] fit 432k + 100 marks p50=0.216ms p95=0.286ms
```

- 断言阈值 16ms，远低于掉帧线。

## 5. 缺口 / 不宣称

1. **F6-A1 的备注内容未验**：T5.2 只做标记存储与跳转，备注编辑在 T5.3；当前备注为空。
2. **F6-A2 的确认对话框未真人点击**：自动化删除入口跳过确认；代码路径为 `QMessageBox::question(..., Yes|No, No)`，需 T5.3/手测补一次“取消不删/确认才删”。
3. **F6-A8 只完成 UI 路径与 V9 短 GOP 数字**：未做正式 P9 冷随机 20 目标、V1、基线机、4K；不把 31.34ms 当成全素材/全机器通过。
4. **长 GOP 标记点击未测**：proxy-V1 的 B→A 仍为 148–157ms（T4.2），T5.2 未在长 GOP 上跑标记点击；按可用档处理。
5. **AppData 回退的 UI 端到端未测**：T5.1 已用真实 ACL 只读目录验证存储回退；T5.2 只在离屏测试验证“%APPDATA% 回退”文案，未在只读素材目录重复 ACL 手测。
6. **更高 schema / 读失败弹窗未自动化**：面板警告条与 `ShowMarkWarnings` 代码路径已接；阻塞类警告会弹框，自动化未覆盖。
7. **关窗 flush 未单独触发**：T5.2 增删即保存，`closeEvent` 的 dirty 重试主要在 T5.3 备注编辑后才会走到。
8. **真人视觉/DPI/4K**：未做 F6-A8 的真人计时、T6.4 DPI 与 T7.7 正式片单。
