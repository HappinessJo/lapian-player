## 2. 自动化命令

```powershell
# 1080p：F/双击/Esc、时间轴、S、焦点隔离、最大化
$p = Start-Process -FilePath (Join-Path $PWD 'dist\lapian.exe') `
  -ArgumentList @('--file',(Join-Path $dir 'snapshot-A.mp4'),'--fullscreen-test') `
  -Wait -PassThru -RedirectStandardError (Join-Path $PWD 'build\t6.1-final-fullscreen.log')
Write-Host "exit=$($p.ExitCode)"

# 1080p→4K：全屏中打开 4K，截图/帧号/交换链
$p = Start-Process -FilePath (Join-Path $PWD 'dist\lapian.exe') `
  -ArgumentList @('--file',(Join-Path $dir 'snapshot-A.mp4'),'--file-b',(Join-Path $dir 'K.mp4'),'--fullscreen-test') `
  -Wait -PassThru -RedirectStandardError (Join-Path $PWD 'build\t6.1-final-fullscreen-4k.log')
Write-Host "exit=$($p.ExitCode)"
```

所有按键都是程序化 `QKeyEvent`（`F`/`Esc`/`Space`/`S`）发到当前焦点控件，双击是 `QMouseEvent(MouseButtonDblClick)`；**不是物理键盘/鼠标**。日志 UTF-8，控制台 GBK 时按 T5.4 记录里的方式解码。

## 3. 结果

### 3.1 1080p：进入/退出、交换链、布局

```text
T6.1 fullscreen_state normal fullscreen=0 frame=100 playing=0 gfx=980x531 swap=980x531 dpr=1.00 timeline=1 info=1 info_frame=帧_100 display=1920x1080 focus=GfxWidget toggle_ms=-1
T6.1 fullscreen_state entered fullscreen=1 frame=100 playing=0 gfx=1620x891 swap=1620x891 dpr=1.00 timeline=1 info=1 info_frame=帧_100 display=1920x1080 focus=GfxWidget toggle_ms=9
T6.1 fullscreen_swap swap-fullscreen gfx=1620x891 dpr=1.00 swap=1620x891 expected=1620x891
T6.1 fullscreen_state timeline-clicked fullscreen=1 frame=60 playing=0 gfx=1620x891 swap=1620x891 dpr=1.00 timeline=1 info=1 info_frame=帧_60 display=1920x1080 focus=GfxWidget toggle_ms=9
T6.1 fullscreen_state exited fullscreen=0 frame=100 playing=0 gfx=980x531 swap=980x531 dpr=1.00 timeline=1 info=1 info_frame=帧_100 display=1920x1080 focus=GfxWidget toggle_ms=18
T6.1 fullscreen_focus before=GfxWidget after=GfxWidget
T6.1 fullscreen_toggle_ms=57
```

| 项 | 普通窗口 | 全屏 | 结论 |
|---|---|---|---|
| 窗口 | 1280×720（构造值） | 1920×1080（等于屏幕） | `covers-screen` 通过 |
| GfxWidget | 980×531 | 1620×891 | 视频区变大，留有侧栏/时间轴/信息栏 |
| 交换链后备缓冲 | 980×531 | 1620×891 | 与 `gfx × DPR` 逐像素一致 |
| 时间轴/信息栏 | 可见 | 可见 | `timeline=1 info=1`，帧号 `帧 100` |
| 全屏内点击时间轴 | — | 点击 x=810 → 帧 60 | 画面/帧号/播放头都到 60，且暂停 |
| 全屏内 `S` | — | 帧 100 → PNG 1920×1080 | `encode_ms=32–38`，保存帧 == 显示帧 |
| 退出后几何 | 1280×720 | 恢复普通窗口 | `geometry-restored`、`gfx-restored` 通过 |
| 退出后焦点 | GfxWidget | GfxWidget | `focus-kept` 通过 |
| 最大化往返 | 最大化 1620×820 | 全屏 → 退出仍最大化 | `maximized-restored` 通过 |

`toggle_ms` 是 `showFullScreen()` 或 `showNormal()+restoreGeometry()` 的墙钟耗时（开发机 8–22ms，最大化往返 57ms）。**不是** spec 指标，也不能当 P1/P9 数字。

### 3.2 全屏中 1080p→4K

```text
T6.1 fullscreen_state 4k-pressed fullscreen=1 frame=60 ... gfx=1620x891 swap=1620x891 ... info_frame=帧_60 display=3840x2160
T5.4 snapshot_saved path=.../K_f60_00-00-02-12.png frame=60 fallback=0 encode_ms=151
T6.1 fullscreen_state 4k-saved fullscreen=1 frame=60 ... swap=1620x891 ... display=3840x2160
T6.1 fullscreen_state 4k-exited fullscreen=0 frame=60 ... gfx=980x531 swap=980x531 ... display=3840x2160
```

- 全屏中打开 4K 后仍在全屏；`display=3840x2160`、帧号 60、信息栏 `帧 60`。
- 4K 截图 PNG 3840×2160，编码 151–174ms（开发机；与 T5.4 的 161ms 同量级）。
- 交换链在切 4K 前后保持 1620×891：**切换分辨率只换纹理，不重建交换链**；窗口 resize 时才重建。

### 3.3 焦点隔离（备注框）

```text
T6.1 fullscreen_check f-in-editor-kept-fullscreen ok=1
T6.1 fullscreen_check s-in-editor-no-snapshot ok=1
T6.1 fullscreen_check esc-in-editor-kept-fullscreen ok=1
T6.1 fullscreen_check editor-still-focused ok=1
```

全屏中聚焦备注框后按 `F`/`S`/`Esc`：不切换窗口、不截图、不退出全屏，焦点仍在 `QPlainTextEdit`。`F`/`S` 作为文本输入被接受，`Esc` 由 MarkPanel 的 `ShortcutOverride`（放行 Esc）+ MainWindow 的 `IsTextInputFocused()` 双保险拦下。

## 4. 结论与不宣称

1. **F1-A6 的自动化范围通过（开发机）**：进入/退出全屏后画面比例（letterbox 单测 + 源显示尺寸不变）、时间轴可点击、帧号/时间码可见可用；交换链跟随 resize 且与 DPR 一致；焦点保持；最大化可恢复。
2. **不是正式验收**：没有 V1/V4/V5 正式片单、没有基线机、没有 4K/DPI 150%/200% 组合、没有多显示器、没有物理键盘/鼠标与真人观看。T6.4 才覆盖 DPI/布局矩阵。
3. **不是性能任务**：`toggle_ms` 只是开发机墙钟，不能当 P1/P9/P11；全屏播放期间的掉帧/underrun 没有统计。
4. **4K 是合成片**：K.mp4 由 V9 放大，不是 spec V4；4K 截图编码 151–174ms 与 T5.4 同量级，仍不是正式 P11。
5. **时间轴点击是程序化鼠标事件**：验证了命中/暂停/帧号路径，不是物理鼠标。
