# T3.6 波形渲染与对齐测量记录

- **日期**：2026-10-20
- **范围**：时间轴波形绘制、W 开关、CFR/VFR bucket→frame 映射、偏移、无音频空态
- **机器**：开发机 Windows 11 x64 / RTX 4060；**不是** 4C/8G/集显基线机
- **代码**：T3.6 提交（本文档随代码提交后记录 hash）；构建 `scripts\build-release.ps1` 通过

## 1. 实现

- `TimelineWidget` 增加 56px 波形带；默认显示，`W` 切换；关闭后恢复 72px 基础高度。
- 波形带顶部仍保留 58px 帧刻度；scrollbar 始终在底部。
- bucket→frame 映射：
  - 每个 x 像素取 `FrameAtX` 得到帧号；
  - 用 `FrameIndex::PtsOfFrame` 取该帧真实 PTS（VFR 也成立）；索引未就绪时用平均帧率回退；
  - 视频区间 `[PTS_f, PTS_{f+1})` 加 T3.4 的 `av_offset` 得到音频区间；
  - 音频区间转成 bucket 范围，`WaveformData::MinMaxRange` 一次锁内聚合 min/max。
- 只画可见 x 范围；按像素列聚合，不逐 bucket 画。
- 无音轨：波形带显示“无音频”；生成失败显示“波形生成失败”；生成中显示“波形生成中…”。

## 2. 对齐 / 交互验证

`lapian_timeline_test` 新增用例：

- `SetWaveformSource` 后 widget 高度 72→**128**；
- 在第 100 帧对应像素列（x=800，8px/帧）注入 click bucket 833，渲染到 `QImage`；
- 检查该列出现波形颜色像素 → **bucket 833 画在 frame100 像素列**；
- `SetWaveformVisible(false)` 高度回到 **72**；
- `ClearWaveform()` 高度回到 **72**。

`lapian_waveform_test` 已验证 V9 的 click 峰值在 frame100 对应 bucket 833 ±5。

## 3. 重绘性能

`lapian_timeline_test` 离屏渲染，1920px：

| 场景 | p50 | p95 |
|---|---:|---:|
| fit 432k 帧（2h@60fps），无波形 | 0.155ms | 0.201ms |
| 8px/帧 + 滚动，无波形 | 0.167ms | 0.213ms |
| fit 432k 帧 + 2h 波形（1.44M buckets） | **0.279ms** | **0.340ms** |

- 2h 波形 fit 的 p95 **0.340ms**，远低于 16ms 预算；只画可见区、按像素聚合。
- 没有在真实 2h 文件上跑端到端；这是合成 bucket 回调的绘制基准。
