# T6.2.1 长按 PgUp/PgDn 连发修复记录

- **日期**：2026-10-20
- **范围**：物理长按 PgUp/PgDn（及 ←/→）最多 3 帧后停止；T6.2 连发补丁
- **机器**：开发机 Windows 11 x64；**不是**基线机
- **代码**：`77248ea`（fix: 长按 PgUp/PgDn 忽略自动重复 KeyRelease）
- **单测**：`ctest` **18/18**（13.90s）
- **分发**：`dist` **32.34MB / 25 文件**
- **验证入口**：`--key-test`（60s / 24fps / `-g 24` 合成片）

## 1. 现象

物理按住 `PgDn`/`PgUp` 时只前进/后退 3 帧就停；`--key-test` 的合成长按却能 2s 走 27 帧。
两者差异在真实键盘的 OS 自动重复事件。

## 2. 根因

1. Windows 长按会持续产生自动重复按键；Qt 在物理长按时不仅发 `KeyPress`，还会发
   **`KeyRelease`**。Qt 官方 FAQ 明确说明：长按会收到额外 `keyReleaseEvents()`，应检查
   `QKeyEvent::isAutoRepeat()` 并忽略。
2. T6.2 的 `HandleGlobalKey()` 在 `KeyRelease` 分支只看 `step_direction_ != 0` 就
   `StopStepRepeat()`，没有检查 `isAutoRepeat()`。第一次 OS 自动重复的 release 一到，
   连发就被停掉。
3. 时间上正好解释 3 帧：按下立即 1 帧；定时器 300ms 后 1 帧；70ms 后 1 帧；约 500ms
   第一次 OS 重复产生 release，停在 3 帧。`--key-test` 的长按只发合成 KeyPress，不发
   自动重复 release，所以 27 帧通过，漏掉了物理路径。

## 3. 修复

[MainWindow.cpp](../src/app/MainWindow.cpp) 的 `HandleGlobalKey()`：

```cpp
if (event->type() == QEvent::KeyRelease) {
  if (is_step && step_direction_ != 0) {
    if (event->isAutoRepeat()) {
      return true;   // Qt 的自动重复 release，不是真正松开
    }
    StopStepRepeat();
    return true;
  }
  return false;
}
```

- 自动重复 `KeyRelease`：吞掉，连发定时器继续。
- 真正松开 `KeyRelease`（`isAutoRepeat()==false`）：停连发，保持原 T6.2 语义。
- 自动重复 `KeyPress` 仍在 `HandleGlobalKey()` 里 `return true`，不额外走帧；连发只由
  300ms→70ms 定时器驱动，避免 OS 重复速率影响帧率。
- 焦点切走/窗口失活仍停；文本/模态让位不变。

诊断：`LAPIAN_KEY_LOG=1` 会输出 `key_event`（KeyPress/Release、auto 标志、方向、当前帧）
和 `step_timer`（before/after），用于以后区分物理/合成键盘问题。

## 4. 回归

`--key-test` 新增两项：

- `autorepeat-release-active`：长按中先确认连发仍在；
- `autorepeat-release-ignored`：注入 `autoRepeat=true` 的 KeyRelease 后连发仍 active。

结果：

| 项 | 结果 |
|---|---|
| `--key-test` 第 1 次 | **77 项，0 失败，exit 0** |
| `--key-test` 第 2 次 | **77 项，0 失败，exit 0** |
| 2s 长按 | **27 帧**（≥20，F3-A3/T2.5） |
| 自动重复 release | active 保持；真正 keyup 后停止 |
| `ctest` | 18/18（13.90s） |
| `--fullscreen-test` | exit 0 |
| `--snapshot-test` | 41/41，exit 0 |
| `--note-test` / `--mark-test` | exit 0 |
| `--ab-test` / `--loop-test` | exit 0 |
| `scripts\build-release.ps1` | exit 0（`[OK]`），dist 32.34MB / 25 文件 |

## 5. 结论与不宣称

1. 根因已修：自动重复 `KeyRelease` 不再停连发；物理长按应持续走帧。
2. **没有在本会话用真实键盘做硬件级长按**：`--key-test` 是 QKeyEvent 合成注入，新增
   用例模拟了自动重复 release 的 `isAutoRepeat()==true` 路径；最终仍需用户用物理键盘
   在 `测试.mp4`/60s 素材上再按一次 PgDn/PgUp 确认。
3. 中文输入法、AltGr、Ctrl+O 原生对话框仍未真人验收。
4. 本补丁不改连发速率（300ms 首延迟、70ms 间隔）、不改焦点让位、不改 T2.9.1 预览。
