## 3. 生成方法

### 3.1 工具

- `C:\Program Files\Red Giant\Trapcode Suite\Tools\ffmpeg.exe`
  （ffmpeg 2.1.4，2014 版；只用于本地 stream copy/重封装，不随产品分发）
- Python 3（V5 改 `stts`；V8 WAV）
- 未联网；没有安装新工具

### 3.2 V1/V6/V7

```powershell
# V1：6:01，1080p24，AAC
ffmpeg -ss 60 -t 300 -i media\测试2.mp4 -c copy -avoid_negative_ts make_zero media\synthetic-suite\V1.mp4

# V6：12:00，1080p24，AAC
ffmpeg -ss 0 -t 720 -i media\测试2.mp4 -c copy -avoid_negative_ts make_zero media\synthetic-suite\V6.mp4

# V7：152s，1080p30，无音频
ffmpeg -ss 0 -t 152 -i media\测试.mp4 -c copy -an -avoid_negative_ts make_zero media\synthetic-suite\V7.mp4
```

> `-ss` 前的 stream copy 会从最近关键帧起，V1 实际 361s；在 3–10min 内。

### 3.3 V5：改 `stts` 造 VFR

1. 先做 30s 视频-only 基片：
   `ffmpeg -ss 0 -t 30 -i media\测试.mp4 -an -c copy build\v5-base.mp4`
2. 用 Python 改写 MP4 `moov/trak/mdia/minf/stbl/stts`：
   - 900 帧；首帧 delta=0；其余每 5 帧 `4×1000 + 1×3000`（timescale 30000）；
   - 去掉 `edts/elst`；更新 `mdhd` duration=1,257,000、`mvhd` duration=41,900；
   - `moov` 在 `mdat` 之后，`stco` 不需要改。
3. 探测结果：`DURATION_US=41900000`、`FPS=21.48`、`VFR_SUSPECT=1`、
   `VFR_DEVIATION_RATIO=0.198`、`HAS_AUDIO=0`。

脚本在 `build/make_v5.py`（gitignore；不随仓库）。如果 build 被清掉，按上面规则重写。
