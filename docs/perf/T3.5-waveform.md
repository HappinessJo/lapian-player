- **日期**：2026-10-20
- **范围**：后台波形生成、200 bucket/s、min/max int16、进度/取消、无音轨
- **机器**：开发机 Windows 11 x64 / RTX 4060；**不是** 4C/8G/集显基线机
- **代码**：T3.5 提交 `93e1f67`；构建 `scripts\build-release.ps1` 通过

## 1. 实现

- `WaveformData`：200 bucket/s，每桶 min/max int16；`offset_seconds` 存 T3.4 的 A/V 偏移。
- `WaveformGenerator`：独立线程 + 独立 `AudioDecoder`/FFmpeg 上下文，输出 48kHz 单声道；不占 UI、不占 WASAPI。
- 每 240 个输出样本一个 bucket（48k/200）；每桶只在边界写一次锁，不是逐样本锁。
- 进度按已解码样本时间/总时长；`Cancel` 设置原子标志并 join，不阻塞播放。
- 无音轨 → `kNoAudio`；失败 → `kFailed`；MainWindow 状态栏显示 `波形：x% / 就绪 / 无音频 / 失败`（T3.6 才绘制）。

## 2. 10 分钟性能（P13）

测试片：`build/sync600.mp4`（proxy-V1 循环 600s，1080p 24fps，AAC 48k 单声道），只在 `build/`，不入库。

```powershell
.\build\release\bin\lapian_waveform_probe.exe .\build\sync600.mp4
```

结果：

```
state=2 elapsed_ms=391.5 buckets=120004 peak=5011 peak_bucket=30023
```

- **391.5ms** 完成 10 分钟波形；spec P13 目标 ≤3s，开发机通过；
- 120004 buckets = 600s × 200/s，bucket 率正确；
- 生成在后台线程，首帧/播放不等待。
