## 2. 自动化序列

```powershell
$dir = Join-Path $PWD 'build\t5.3-notes'
New-Item -ItemType Directory -Path $dir -Force | Out-Null
Copy-Item '.\media\V9.mp4' (Join-Path $dir 'A.mp4') -Force
Copy-Item '.\media\V9.mp4' (Join-Path $dir 'B.mp4') -Force
.\dist\lapian.exe --file (Join-Path $dir 'A.mp4') `
  --file-b (Join-Path $dir 'B.mp4') --note-test
```

序列（`MainWindow::SetMarkNoteForTest` 选中标记并写入编辑框，但不提交；与用户点击行、键入文本走同一组控件）：

1. 打开 A，跳到帧 100，`Ctrl+M` 添加标记；sidecar 生成；
2. 在标签/备注框写入“转场A / 第一行\n第二行”，**不提交**；
3. 焦点切到备注框后调用 Space 路径，确认不播放（spec §3.7）；截图；
4. 直接触发 `closeEvent`（不隐藏窗口），验证关窗前 flush；重开 A 校验内容一致（F8-A2）；
5. 重开后的标记点击 → `frame=100, playing=0`（F6-A1）；
6. 把标签/备注清空并显式提交；重开仍为空（允许空备注）；
7. 写入“转场B / 第二版\n覆盖保存”，关窗；重开校验覆盖保存；
8. 20 次“写标签/备注 → 提交”，记录每次 `SetMarkText + Save` 耗时；重开校验最后一次内容；
9. 删除确认对话框：先点 **No**（默认按钮）确认不删；再点 **Yes** 确认删除、列表归零、最后标记删除后 sidecar 消失（F6-A2）；
10. 打开 B：0 标记、无 B 的 sidecar（F8-A3）。

### 3.3 焦点隔离（spec §3.7）

```text
T5.3 note_focus focused=1 playing_before=1 playing_after=1
T5.3 note_check focus-blocks-space ok=1
```

- 备注框获得焦点后走 Space 路径，播放状态保持暂停。
- 离屏单测额外断言：备注框接受 Space/W/Ctrl+M 的 `ShortcutOverride`，全局 QAction 不会拿到这些键；标签 Enter 提交、备注普通 Enter 换行、Ctrl+Enter 提交。
- 实现：`MarkPanel::eventFilter` 在编辑框上接受除 Esc 外的 `ShortcutOverride`；`MainWindow` 的 `TogglePlayback`/`ToggleWaveform`/`ShowGotoDialog`/`OpenDialog` 以及既有的循环/速度/缩放/静音/添加标记入口都检查 `IsTextInputFocused()`；`MarkPanel::DeleteCurrent` 在编辑框聚焦时让位。

### 3.4 保存耗时（20 次提交）

```text
T5.3 note_perf note_save_n=20 p50=6.19ms p95=7.38ms max=7.38ms
```

- 每次“标签/备注提交”都会 `MarkStore::SetMarkText` + 原子写 sidecar；20 次 p95 7.38ms，远低于一次 UI 操作的感知阈值。
- 只在失焦/Enter/Ctrl+Enter/切换选中/切文件/关窗时提交，不做逐键保存；列表只更新当前行（单测断言 `topLevelItem` 指针不变、选中不变）。
- 这不是 spec §4.1 的 P 指标，只用于确认“即时保存”不引入可见卡顿。

## 4. 口径与决策

1. **Enter 语义（规格歧义，明确记录）**：spec §3.6 写“失焦或回车即时保存”，但多行备注需要 Enter 换行。本任务采用：
   - 标签：`Enter` 保存；
   - 备注：`Enter` 换行，`Ctrl+Enter` 保存；
   - 两者失焦、切换标记、切文件、关窗都保存。
   这符合 spec §3.7“文本框聚焦时除 Esc/Enter 外不触发全局快捷键”的局部按键语义，但“备注的回车保存键是 Ctrl+Enter”是对 §3.6 的收窄解释。若后续要改成备注 Enter 保存，只能做单行备注，需走 spec §9 版本记录，本任务不静默改 spec。
2. **Esc**：编辑框不拦截 Esc（`ShortcutOverride` 放行），留给后续全屏退出的全局语义；当前无全屏，Esc 在编辑框内无动作。
3. **标签 trim**：保存时去掉标签首尾空白；全空白标签按空处理，列表显示回退名“帧 N”。
4. **不改 schema**：仍用 T5.1 的 `lapian.marks` schema v1、`SetMarkText` 更新 `updated_at`；没有新增保存按钮、没有导出/分享。

## 5. 缺口 / 不宣称

1. **真人键盘/输入法未手测**：自动化用 `QApplication::sendEvent` 与程序化文本框输入；中文 IME 组字、AltGr、真实窗口焦点切换仍要在 T6.2/F7 手测矩阵补。
2. **F6-A8 不是正式 P9**：本节只有 V9 1080p 短 GOP 的标记回归数字；没有 V1/4K/基线机/冷随机 20 目标。
3. **F4-A2 长 GOP 未改善**：`--loop-test` 用 `测试.mp4` 的短 GOP；proxy-V1 的 B→A 148–157ms 仍是 T7 优化项。
4. **AppData 回退的编辑端到端未重测**：T5.1 已用 ACL 只读目录验证存储回退；T5.3 的编辑保存只跑可写目录，未在只读素材目录重复 ACL 手测。
5. **关窗失败分支未自动化**：保存失败时“仍要退出吗？”对话框与备注 flush 的组合没有构造失败盘；代码路径与 T5.2 的 `FlushMarksOnClose` 相同。
6. **列表内联编辑未做**：编辑只在底部详情区，未做 QTreeWidget 就地编辑；不是验收要求。
7. **排版/DPI**：编辑器固定 88px 高，未做 T6.4 的 DPI/布局验收。
