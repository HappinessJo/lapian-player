## 2. 设计结论（S3 定稿；DEC 已拍板）

1. **顺序**：M1（durl 720p 单文件）→ M2（DASH 双输入 1080p）。M1 是最小可交付切片，不等于砍掉 1080p。
2. **唯一共用新基础设施**：可增长读层（`GrowingSource` + 每读者 `Cursor` + 阻塞 AVIO + 取消）。S2 单读者已验证；T8.4 必须补 4 读者/取消/死锁压测。
3. **MVP 顺序下载**：`.part` 是连续前缀，不做稀疏 Range 跳取；未缓存远跳按“剩余字节 ÷ 速率”等待，UI 给进度与取消。跳取优化留候选池（避免范围表/空洞/崩溃恢复的复杂度）。
4. **DASH 不 remux**：视频/音频各一个 `AVFormatContext` + 各自缓存；复用 v1 已独立的音频上下文；共享时钟与 seek 协调。1080p 必须走 DASH（durl 1080p 仅 1/3）。
5. **缓存**：`%LOCALAPPDATA%\拉片软件\cache\<bvid>\<cid>\<qn>-<codecid>\`；20GB 默认 + LRU + 可清；缓存命中零网络。
6. **记录**：在线标记/备注存 `%APPDATA%`（`lapian-online-1`），截图存图片目录 + `index.jsonl`；清缓存不丢记录。
7. **隐私**：只收 SESSDATA，DPAPI 加密；只发 `api.bilibili.com`，不发 CDN；不落日志；本地模式零网络/懒加载。
8. **档位**：默认 AVC ≤1080p，顺序 1080P60→720P60→1080P30→720P30→480P30；4K 只手动、可用档、非 MVP 验收。**B 已拍板**：1080P60/720P60 AVC 可自动、HEVC-only 手动；4K 手动；无大会员账号则 T8.15“未验证”。

## 3. 拍板结果（已全部拍板，2026-10-23）

### 3.1 B：大会员档条件验收

- **大会员功能做**：1080P60/720P60/4K SDR 进档位菜单与播放路径；1080P60/720P60 AVC 可自动，HEVC/AV1-only 只手动、不静默降帧；4K 只手动、标可用档。
- **独立条件验收**：T8.15/O11/OP9/OP10；有大会员账号才执行，无账号写“未验证”；**不进 M1/M2 门**。
- **不承诺**：4K P7/P9/颜色；HDR/杜比/10-bit 颜色；4K 默认自动。

### 3.2 DEC-1…DEC-5：全部按建议

| 编号 | 拍板结果 |
|---|---|
| **DEC-1** | **A：M1 → M2** |
| **DEC-2** | 起播 p95 ≤5s；已缓存 P7 ≤80ms；缓存命中 ≤2.5s；未缓存提示/取消 ≤100ms；任务完成率 ≥80%；p95 按每条 BV 单独算，记录 p50 |

## 4. 额外规格假设（默认沿用 v1；不同意请说）

- **A1**：在线打开仍停在第 0 帧、不自动播放；“起播”= 首帧呈现且可交互（沿用 F1-A2）。若要自动播放，需改 O2 与 F1-A2 在线语义。
- **A2**：在线记录键 bvid+cid；清缓存不丢标记/截图。
- **A3**：默认只选 AVC ≤1080p；1080P60 AVC 可自动；HEVC/AV1-only 的 60fps 与 4K 只手动、可用档（B 口径）。
- **A4**：MVP 顺序下载，不跳取；未缓存远跳按顺序等待。
- **A5**：在线只在用户提交/确认后联网；不预取其他视频、不遥测。
- **A6**：HTTP 客户端（WinHTTP / libcurl）由 T8.2 用产品实际栈自检后定，S3 不预设；结果补进 ADR-007 评审记录。
- **B1**：无大会员账号时，O11/T8.15 只能写“未验证”，不得用普通账号冒充。
- **B2**：4K 只做 SDR 可用档；HDR/杜比/10-bit 颜色正确不在 B 范围。

## 7. 不要做

- 不要把 4K / 1080P60 写成 MVP 验收项（普通用户不可达）。
- 不要把未缓存区写成 P7 ≤80ms；只承诺已缓存区。
- 不要把 ADR-007 的“附条件接受”当成无条件通过；T8.2/T8.4 未过前不按 D4 大规模开工。
- 不要把 durl 1080p（S2 1/3）当成 1080p 保证。
- 不要在启动/本地打开时联网；不要把 Cookie 写日志/入库/meta。
- 不要为了“全量缓存后再播”牺牲几秒起播；也不要在 MVP 做稀疏 Range 跳取。
- 不要把合成/代理素材当成正式 OB 样本；不要把 60fps 源的 29.4fps 副本写成 60fps 通过。
