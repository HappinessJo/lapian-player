# T2.4 逐帧步进验证记录

- **日期**：2026-10-19
- **任务**：[tasks.md](../tasks.md) M2 / T2.4
- **状态**：±1 步进、边界 clamp、步进暂停、画面/帧号/时间码同步、步进后继续播放完成；LRU/预取缓存与音频静音钩子（T3 接入）未完成。
- **范围**：PgUp/PgDn/左/右 ±1；不接长按连发（T2.5）和输入框（T2.6）。

## 1. 实现

- `MediaSession` 增加 `FrameIndex`：打开时同步建索引；索引失败不阻塞打开，步进按钮禁用。
- `MediaSession::SeekToFrame`：可靠索引时从关键帧解码到目标帧；不可靠时从头解码计数；成功后解码器停在目标帧之后。
- `MainWindow::GoToFrame`：暂停播放 → seek → 更新画面/信息栏 → `PlaybackController::SetPosition`，保证下一步播放从目标帧之后继续。
- `PlaybackController::SetPosition`：同步当前帧号/PTS、清 pending；`Play()` 从目标帧之后继续，不回到旧位置。
- 快捷键：PgUp/Left 上一帧，PgDn/Right 下一帧；`GfxWidget` 与窗口 QAction 双路径。
- 边界：`ClampFrame` 到 `[0, size-1]`；首/末帧再按不越界。
- 步进强制暂停；音频尚未接入，`Pause()` 就是静音钩子的占位。
- **未做缓存**：每次步进走一次 seek；真实 1s GOP 冷 seek 约 10–30ms，已低于 P7 80ms。LRU/预取留到 T2.5/T5.4 前统一做。

## 2. 验证

- V9 打开后按 PgDn：信息栏 `帧 1`、`00:00:00:01`，画面为 V9 第 1 帧（黑），状态栏“第 1 帧”。
- 步进后按 Space：从第 1 帧继续播放，约 0.6s 到第 15 帧；未回到第 0 帧，说明 `SetPosition` 生效。
- `lapian_seek_engine_test` 覆盖 V9/proxy-V1/真实 1s GOP 的固定帧和 20 随机帧，PTS 全精确。
- 2s GOP 专项：`build/test-media/real-gop2s-full.mp4` 20 随机帧 **max 78.33ms**，低于 P7 1080p ≤80ms（本机 RTX 4060，冷 seek；非基线机）；未收紧到 1s。
