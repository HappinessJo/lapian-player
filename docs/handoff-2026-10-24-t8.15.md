## 1. 本轮做了什么

1. 新增独立探针 **`--online-vip-test`**（`src/app/OnlineVipTestRunner.*`）：
   - `--vip-catalog-only`：只读默认 DPAPI/`--vip-sessdata-file` → nav → view →
     `playurl(fnval=4048)`；分别以 `qn=80`（产品自动请求）与 `qn=120`（最大请求）
     各拉一次目录，打印实际 qn/codecid/fps/尺寸/带宽/手动标记/菜单模型；
   - GUI（默认）：`MainWindow::StartOnlineSession` 按
     `requested_qn/requested_codecid` 打开，记录实际档位/fps/降帧横幅/菜单，
     已缓存 PgUp/PgDn 严格 ±1 与 p95，4K 播放/逐帧，高档→1080P30 切档的
     缓存/记录/标记/PTS；
   - 选项：`--vip-qn`、`--vip-codecid`、`--vip-expect-auto`、
     `--vip-play-seconds`、`--vip-seeks`、`--vip-switch-qn`、
     `--vip-sessdata-file`；复用 `--bvid/--cid/--tag/--timeout-ms`；
     `--ui` 不需要显式加（默认走窗口；`--vip-catalog-only` 无 GUI）。
2. **未改** `OnlineSession`、M2 runner `nav_normal_user` 语义、M1/M2 门/数字、
   OB 样本、`lapian-cache-1` schema、默认 AVC≤1080p、T8.13 加固、T8.12 默认
   策略、T8.10 DASH 语义、T8.6.1a/b 语义、`MainWindow` 预览路径。
3. `MainWindow.h` 只加一个只读 getter `OnlineCodecidForTest()`（inline，
   无行为改动）。
4. 文档/台账：本文件、[证据](perf/v2-online-vip.md)、`tasks-v2.md` v0.29、
   `AGENTS.md` v6.41。

## 2. 真实目录（大会员）

### OB-2 `BV1mA411m7pS` / cid `1004967230`（96s）

- qn=80 与 qn=120 请求返回**相同** 15 条视频流；`DefaultQn=116` AVC。
- **116 AVC**：1920x1080、fps **62.500**、4,221,714bps；同档还有 HEVC 58.824 /
  AV1 60.150。
- 80 AVC 29.412 / 64 AVC 29.412 / 32/16 29–30。
- **qn=74 不存在**；**qn=120 不存在**。
- 结论：普通用户只到 qn=80，大会员下同一条 OB-2 出现 1080P60 AVC；标题
  “60FPS”与 API fps 62.5/容器 60.0 并存，以实际目录 + 容器为准。

### 4K SDR `BV1afnv6GEDA` / cid `42913040245`（27s，2160x3840 竖屏）

- **120 AVC/HEVC/AV1 均 60.000fps**，AVC 25.9Mbps、HEVC 5.19Mbps、AV1 5.36Mbps；
  116 AVC 60fps；80 AVC 30fps。
- 自动 `DefaultQn=116`，**不自动选 4K**；`requested_qn=120` 可手动打开。
- 4K60 SDR；OP10 只记录能开/能播/逐帧不崩，不承诺 4K 性能/颜色。

### 其他候选

- `BV1dJjv6PEWF`（4K HDR，15P/2399s）：目录有 qn=120 3840x2160@59.932；
  **HDR 只做目录，不作为 SDR/颜色通过**。
- `BV1e1h46LEHk`：`view` 62002 不可见，未测。
