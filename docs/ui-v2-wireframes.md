# 拉片软件 UI v2 低保真线框（3 张）

- **状态**：定义阶段产出（2026-10-25），**待用户批准**；配合
  [ui-v2-definition.md](ui-v2-definition.md) 阅读。
- **用途**：锁骨架、分区、信息归属与控件存在性；**不定视觉细节**
  （颜色/字号/圆角/图标在规划阶段出设计令牌）。
- **尺寸口径**：以下像素均为 **100% DPI 的逻辑像素**，窗口 1280×720（现状默认）；
  视频区按 flex 收缩，其余栏位高度来自令牌（§定义 §7.2）。
- **硬约束**：视频区是独立 HWND，**图上没有也不允许出现"浮在画面上的控制条"**。
  图上一切控件都在画面外；空态/错误态的卡片是"隐藏 HWND 后"的 Qt 占位（待决 Q1）。

**行为与边界**

- 空态**没有**黑色空视频区：`GfxWidget` 隐藏，用 Qt 卡片承载两个入口与支持范围

**行为与边界**

- **帧号是主锚点**：`帧 203` 用最大字号（建议 28px/600），位置固定在 Transport 中央；
  点击进入内联编辑（Enter 提交、Esc 取消），`Ctrl+G` 对话框保留。
- Transport 左起：末帧、上一帧、播放/暂停、下一帧、首帧；中间帧号+时间码+总帧；
  右侧循环（`A 120–B 240` 点击可清）、速度（`◉ 1.0x`）、音量、波形开关。
  每个按钮的 tooltip 标注 `spec.md` §3.7 键位（如"上一帧 PgUp / ←"）。
- 循环开启时色条与 `A/B` 数值同时可见（色 + 文字双编码，见定义 §5-P6）。
- Inspector 展开时**只挤压视频区宽度**，不改变 Transport/时间轴高度；
  折叠后视频区变宽、Inspector 变 44px 竖条。
- 横幅在顶栏下方**推下**视频区，不覆盖画面与时间轴；同一时刻最多一条（T6.5 语义）。
- 状态栏：左侧 1 条主动消息，右侧 3 个次级指标；**不再**放音量滑条、设置按钮、
  循环/速度状态（已移到 Transport）。
- 原 `InfoBar` 的 5 类信息按此拆散：文件名→顶栏、规格→顶栏副标题、
  帧号/时间码/总帧→Transport、提示→Banner 槽、存储位置→Inspector 页脚。
- 视频区在 100% 下目标 ≥ 客户区高 68%（示例 508/720=70.6%）；现状是 530/720=73.6%，
  但那 34px 的 `InfoBar` 不可读（§定义 1.2）。新壳用 212px 固定栏换可用的控件与信息,
  200% DPI 走紧凑档（186px）→ 58.9%。规划阶段用真实窗口尺寸复核，不降低门槛。

  降帧横幅仍可关闭、且关闭后角标保留（既有语义）。

## 5. 三张图共同遵守的"不做"

1. **不**在画面上叠控制条、进度条、角标、按钮（HWND 冲突）。
2. **不**把帧号放到画面角落或悬浮层。
3. **不**做无边框窗口/自绘标题栏（本轮）。
4. **不**用动画（淡出/滑动）掩盖状态切换。
5. **不**新增功能入口（播放列表、最近文件、导出、多轨…）。
6. **不**改键位、帧号语义、点击即暂停、拖动降质/松手精确。
