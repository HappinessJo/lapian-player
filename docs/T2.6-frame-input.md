## 1. 实现

- `Ctrl+G` 窗口 QAction + `GfxWidget` 的 Ctrl+G 双入口，打开 `QInputDialog`。
- 接受：
  - 0 基整数帧号；
  - CFR 的 `HH:MM:SS:FF`，用 T2.1 `TimecodeFormatter`（NDF，23.976→24 等）；
  - VFR 的 `HH:MM:SS:FF`：按 nominal fps 换算时间，再用 `FrameIndex::FrameOfPts` 找最近帧。
- 越界：`ClampFrame` 到首/末帧并提示“已到边界”。
- 非法/负数：不跳转，`QMessageBox` 可读提示。
- 成功：`GoToFrame` 暂停播放、seek 到目标、更新画面/信息栏/时间码，并同步 `PlaybackController` 位置。
- `--goto <text>` 是自动化验证入口，与输入框共用 `ApplyGotoText`。

## 2. 验证
