## 2. 本轮做了什么

### 2.1 根因：四个“提示/边界”问题 + 一个真实冻结

1. **断网 UNC 会让 UI 冻结 ~21s。** `avformat_open_input` 在 UI 线程同步打开；
   不可达 SMB 主机默认 20s 级超时，直接违反 spec §4.4 的 5s。
   实测：`lapian_media_probe \\192.0.2.1\share\x.mp4` **21,053.9ms**；
   同一路径 `GetFileAttributesW` **21,034.4ms**。
2. **长路径 sidecar 误回退。** >MAX_PATH 中文目录里 Qt 能创建临时文件，但
   `ReplaceFileW` / `MoveFileExW` 不带 `\\?\` 前缀，替换失败后 MarkStore 按
   设计回退 AppData；用户看到的存储位置会“莫名其妙”跑到 AppData。
3. **正斜杠路径错误分类。** Qt 文件对话框给 `E:/...`；不存在的文件被 FFmpeg
   当 URL，返回 `EILSEQ`，提示变成“无法打开文件 / Illegal byte sequence”，
   而不是“文件不存在”。
4. **目录/被独占文件提示误导。** 目录被 FFmpeg 报 ENOENT/权限；独占文件被
   报“文件不存在”；用户无法判断是路径问题还是占用。
5. **无自动化回归。** V8/损坏/只读/设备丢失/长路径/网络盘此前只有零散手测；
   没有一条“5s + 旧会话保留 + UI 仍可用”的产品路径探针。

### 2.2 改动

- **`media/PathProbe.{h,cpp}`**（新增）：`IsNetworkPath`（UNC、`\\?\UNC\`、
  映射网络盘）与 `ProbePathWithTimeout`（工作线程 + 3s 上限；超时 detach，
  线程只持有自有 Win32 状态）。单测 `lapian_path_probe_test`。
- **`MainWindow::OpenFile`**：网络路径先预检；本地存在文件先试读（区分
  独占/ACL）；目录直接提示；路径统一 `QDir::toNativeSeparators` 后再交给
  FFmpeg/索引/音频。新增 `last_open_error_` / `last_navigation_error_`。
- **`MarkStore::WriteAtomically`**：`NativeLongPath()` 给 ReplaceFileW/
  MoveFileExW 加 `\\?\`（UNC 用 `\\?\UNC\`）；长路径 sidecar 不再误回退。
- **`AudioEngine::SimulateDeviceLossForTest`**：测试开关，复用
  `HandleDeviceLost`（silent + 时钟失效 + 2s 重试）；模拟期间不反复重开设备。
- **`app/RobustTestRunner.{h,cpp}`**（新增）：`--robust-test` 产品路径探针；
  支持 `--robust-media/--robust-tag/--robust-root/--robust-only/
  --robust-readonly-dir`；25ms 模态框守卫；90s 总超时。
- **`MainWindow` ForTest**：`SimulateAudioDeviceLossForTest`、
  `LastOpenErrorForTest`、`LastNavigationErrorForTest`、
  `SetMarkAppDataRootForTest`（只读回退不写真实 `%APPDATA%`）。
- **`scripts/robust-readonly.ps1`**（新增）：真实 ACL 只读目录验证；
  `icacls /deny` → 验证不可写 → 跑 `--robust-only readonly` → `finally`
  恢复 ACL。
- **测试**：`tests/path_probe_test.cpp`（新）；`mark_store_test` 增加
  “>MAX_PATH 中文长路径 sidecar”11 项断言。`ctest` 21 → **22**。

### 2.3 没做什么

- 没有把打开流程整体异步化；网络预检是同步等待最多 3s（满足 5s 上界，
  见 §4 缺口）。
- 没有改拖动/缓存/4K 语义（T7.4 未重开）；没有改 T7.1/T7.2/T7.3 判定。
- 没有为 5s 放宽任何既有阈值；没有为了“通过”隐藏网络/长路径失败。
- 没有新增产品功能；`--robust-test` 与既有 `--drag-test` 一样只在测试入口。

## 4. 口径 / 不宣称

- **V8 没有正式素材**：7 类合成坏文件覆盖“损坏/不支持/不存在/目录/截断/
  无视频流/占用”；真实下载损坏片的人工验收仍未做。
- **设备丢失是模拟**：复用 `AUDCLNT_E_DEVICE_INVALIDATED` 同一状态机，
  但**不是物理拔 USB 声卡/禁用设备**；设备恢复的听感、真实重连时间未验收。
- **网络盘只测失败路径**：可达 SMB 共享上的成功打开、sidecar 写、截图未测；
  本机非管理员，`\\localhost\E$` 打开被拒。这一项不能写成“网络盘通过”。
- **只读目录是即时 ACL**：脚本设置/恢复；没测长期只读目录、继承 ACL、
  网络只读共享。
- **没有磁盘满/IO 错误注入**：sidecar 双写失败由 T5.1 单测覆盖，截图写入
  失败由 T5.4 目录回退覆盖；真实磁盘错误未做。
- **没有崩溃恢复测试**：原子写语义由 T5.1 覆盖；没有写盘中途强杀进程。
- **不是基线机/冷缓存**：开发机 6C/12T + RTX 4060 + 32GB。
- **UI 在网络预检时最多阻塞 3s**：满足“未响应不超过 5s”，但不是完全异步。
- **T7.3 仍未关闭**：V10 2h 未做、P14 未通过；T7.4 仍只是 4K proxy。
- 没有真实 V1–V10、HDR/10-bit、物理 DPI/多显示器、RDP/集显；留 T7.7。
