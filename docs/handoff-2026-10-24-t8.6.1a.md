## 2. 接口与状态机（给 T8.6.1b / T8.9）

```cpp
// MainWindow 私有（T8.6.1a）
bool OnlineStepEligible() const;   // online_ready && !cache_hit && session->IsGrowing
std::int64_t OnlineLastFrame() const;  // 完整索引→容器总帧→部分稳定帧 − 1
bool ApplyOnlineStep(int direction);   // 返回 false：边界/索引不可定位/失败 → 停连发
void IssueOnlineStepSeek(std::int64_t target, bool cached);
void OnOnlineStepLanded(std::int64_t target);  // 成功后：trace + 推进排队
void OnOnlineStepFailed(std::int64_t target);
void ResetOnlineStepState();
void ShowOnlineWaitPrompt(std::int64_t target);  // “缓冲中（目标帧 N）”
```

状态字段（`OnlineStepState`）：`desired`、`inflight/inflight_target/inflight_cached`、
`queued/queued_target/queued_cached/queued_direction`、`seeks/retargets/boundary_stops`、
`trace`（≤512）。语义：

- **已缓存**：单格排队；tick 在途时只排一步，落地后再排；屏幕序列逐帧连续。
- **未缓存**：最新目标优先；tick 触发 `RequestOnlineSeek` 取消旧等待并重定向，
  提示同步更新；不承诺逐帧。
- **边界**：`next` 越界即停连发；在途的步仍可落地；不 seek 越界帧。
- **短按**：单步；快速双击排 1 格；松开不取消已发出的那一步。
- **外来 seek**：从 `online_seek_target_`（状态栏目标）±1。
- **失败**：清状态、停连发，保留既有错误提示。

测试 hook（产品路径转发，不改语义）：

```cpp
qint64 OnlineLastFrameForTest() const;
bool OnlineFrameCachedForTest(qint64 frame) const;
bool OnlineStepIdleForTest() const;      // !seek_running && !inflight && !queued
QString OnlineStepStateForTest() const;
std::vector<qint64> OnlineStepTraceForTest() const;  // 落地帧序列
void ResetOnlineStepTraceForTest();
int OnlineStepBoundaryStopsForTest() const;
int OnlineStepRetargetCountForTest() const;
```

T8.6.1b（拖动预览）可复用 `OnlineStepEligible`/`OnlineFrameCached`/`ShowOnlineWaitPrompt`
和“重建会话带索引”的修复；不要复用 `ApplyOnlineStep` 的排队语义做拖动（拖动需要
预览帧限流，不是单步队列）。

## 5. 已知缺口 / 风险

1. **未缓存区不逐帧**：只保证提示/取消/落点（OP3）；按住时跳中间帧是设计取舍。
2. **弱网/限速未测**：真实 CDN 1.3–2.0MB/s 远高于素材码率，正常前进几乎碰不到
   未缓存边界；未做 netsh/代理限速，也没有 <0.5x 实时网络下的 30s 长按。
3. **单格背压会少走一步**（OB-2 25/26）；这是“不跳帧”优先的取舍。
4. **只测 2s 长按**；未做 30s/浸泡；trace 上限 512。
5. **4K/1080P60/DASH 未测**；OB-2 1080P30 只作真实样本。
6. **UI 心跳 16ms**：只证明无 >200ms 事件循环停顿，不是渲染帧率/掉帧测量。
7. **Medium 副本只测显式测试根**：没有用默认缓存根（命中会是本地同步路径）；
   默认根/缓存命中由 T8.7/T8.8 覆盖。
8. **探针需要增长会话**：缓存命中时 `growing_session` 会失败；用
   `--longpress-fresh-cache` 或新的 `build\t8.6.1a-*` 根。该 flag 只删显式传入
   （或默认测试）的缓存根，不碰用户默认缓存。
9. **末帧边界会留下远端等待**：关窗取消并 join（377–618ms），没有等它落地。
10. **真实扫码/大会员/4K**：不涉及；T8.15 仍“未验证”。
