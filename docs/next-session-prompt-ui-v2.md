## 4. 已知硬约束（定义/规划阶段必须写进文档）

1. **视频区是独立 HWND**：`GfxWidget` 使用 `WA_NativeWindow` / `WA_PaintOnScreen`，
   随意在画面上叠 Qt 控件会与 D3D11 子窗口冲突；优先把控制放在画面外。
2. **Qt Widgets + 冷启动**：不引入 QML/Electron/重型框架；ADR-004 已定。
3. **键位与帧语义是产品契约**：`spec.md` §3.7；改键位要单独走 spec 版本记录。
4. **测试耦合**：`--key-test`、`--dpi-test`、`--banner-test`、截图/布局断言
   依赖 objectName/几何；重做前先列“哪些测试要改、哪些不能改”。
5. **性能路径不能碰**：`GfxWidget` 呈现、`PreviewDecoder`/`DragStrategy`、
   `OnlineSession` 状态机、缓存；UI 重做只做壳与视图。
