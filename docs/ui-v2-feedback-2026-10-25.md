## 2. 原型里怎么改的

1. **时间码为主读数**：Transport 正中改成 26px 等宽 `00:00:06:23`；下一行小字
   `帧 0203 / 总 4573`。标尺刻度也改成写全 `00:00:06:23`——半秒级缩放时
   `05:15` 会被读成"5 分 15 秒"，写全才不歧义。讨论面板仍可切
   `时:分:秒:帧 / 秒 / 纯帧号` 对比。
2. **两条滑块，位置按 AE**：
   - 上方细条 = **视图窗**（拖两端 = 缩放，拖中间 = 平移，滚轮以指针为中心）；
   - 下方粗条 = **工作区 = 循环区间**（拖两端改 A/B，拖中间整体平移，
     点空白处把区间移过去），默认 `A=0 / B=末帧 / 循环开`；
   - 循环开关按钮移到 Transport 右侧、紧挨波形开关，默认高亮；
   - 时间轴标题栏显示 `工作区 全片 · 循环开`；工作区外的画面在时间轴上**压暗**
     （AE 的做法），一眼看出哪段在循环。
3. **播放头永不消失**：
   - 跳帧（含点右侧标记）时，如果目标帧不在当前视图内，**先把视图滚过去**
     （留 40% 余量），再落帧；
   - 即使手动把播放头滚出视图，也会**贴边画一个箭头**，不再整体跳过绘制；
   - 补 `ResizeObserver`：折叠/展开检查器时画布尺寸变化会重画（原来只在
     `window.resize` 时重画，过渡期间画布会被拉伸）。
   - 自测（`?smoke=1`）：把视图缩到 150–420，逐个点 7 个标记，
     `playhead_offview=0`。
4. **光标**：时间轴画布 `cursor: crosshair` → 默认箭头；只有滑块的把手
   保留 `ew-resize`（否则没法提示能拖）。

## 3. 顺带修掉的

- 空状态时两条滑块压到 30% 透明度并禁用（原来空态也画着一条"工作区"）；
- 空状态检查器的标签/备注输入框置灰；
- 窄窗口（≤1180）缓冲文字只留进度条，避免把 Transport 挤爆；
- 标记帧号在小条里加了深色底片，不再和波形糊在一起。
