## 2. 实现要点

1. **安装器**：`UninstallFilesDir={localappdata}\拉片软件\uninstaller`，把
   Inno 卸载器移出应用目录，使安装目录只含应用负载；安装目录导入表通过。
2. **卸载缓存清理**：`[Code]` `InitializeUninstall` 弹“是否同时删除在线
   缓存？”——默认“否”，只删 `%LOCALAPPDATA%\拉片软件\cache`；静默卸载默认
   不删，显式 `/CLEARCACHE` 才删。`CurUninstallStepChanged(usPostUninstall)`
   执行 `DelTree`，不碰记录/截图/设置/凭据/marks/sidecar。
3. **隐私/许可**：新增 `packaging/PRIVACY.txt`，安装前 `InfoBeforeFile` 展示；
   README 更新在线/缓存/凭据/卸载；`THIRD-PARTY-NOTICES.md` 补 WinHTTP；
   `OnlineResolveDialog` 首次隐私说明补缓存位置/无遥测/无自动更新/无崩溃上报。
4. **打包**：`package.ps1` 要求并复制 PRIVACY、检查 BOM，报告记录隐私/卸载
   口径；`check-imports.ps1` 对 stage/setup/安装目录继续断言无网络栈导入。

## 3. 关键数字

- 安装：setup 11.79MB；`{app}` 33 文件/34.43MB；安装器 0 TCP/UDP
  （12–13 采样）；Medium；无 Qt PATH 直接启动。
- 默认缓存：OP5 10/0，ready 120.7ms，qn=80，0 playurl/DASH/quality/HTTP；
  默认缓存 13 条/338,893,051B（只读扫描）；cache-manage 默认 AppData 75/0。
- 凭据：合成 sentinel 写入 `%APPDATA%\拉片软件\credentials.dat`，DPAPI
  解密通过；原文件恢复（SHA-256 `F406C6E9...`）。
- 卸载：默认保留缓存 26/338,893,051B；`/CLEARCACHE` 删除合成缓存 59B；
  真实缓存 26/338,893,051B 备份/恢复；用户数据 SHA-256 全部一致。
- 回归：ctest 35/35；key-test 77/0；O9 65 采样 0 TCP/UDP；
  P1 p95 308.81ms / P2 361ms / P7 back 1.63ms / fwd 0.34ms（热缓存，
  非 F1-A1）；M2 引用 T8.14 3/3 34/0。

## 4. 缺口 / 未验证

- **未真删真实 20GB 缓存**：合成小缓存验证逻辑；真实默认缓存保护后恢复。
- **Inno 卸载器静态 winhttp 导入**：在 `{app}` 外；安装/卸载 0 TCP/UDP，
  但二进制仍有静态导入。若验收把卸载器算入安装目录网络栈，需换卸载器方案。
- 安装器 UI 英文、未签名、无自定义图标；杀软未验证。
- 未用 Explorer 真双击；直接 `ProcessStartInfo` 从 C: 启动，不是 F1-A1。
- 未测：安装时 App 运行、跨版本升级/降级、Windows 10 21H2、干净机器冷缓存。
- **T8.14 残余风险保留**：1 次 teardown `0xC0000374`、1 次 L-1 seed 卡住
  未定位/未复现；本轮不写“无崩溃/已证明稳定”。
- **T8.15 未做**（无大会员账号 → 未验证）；**T8.6.1b 未做**。
- 安装/卸载 0 网络是 netstat 轮询 + 静态导入 + 日志，不是抓包级证明。
