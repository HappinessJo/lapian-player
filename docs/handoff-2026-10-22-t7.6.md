## 2. 本轮做了什么

### 2.1 新增脚本与资产

- **`scripts/package.ps1`**（新增）：一条命令完成
  dist 校验 → stage（dist + `licenses\` + `README.txt`）→
  `lapian_env_check.exe` → `check-imports.ps1` → 便携 zip → Inno 编译 →
  P12/SHA-256 报告。输出统一到 `out\package\`（gitignore）。
  支持 `-SkipBuild` / `-SkipInstaller` / `-SkipZip` / `-Version` /
  `-DistDir` / `-OutDir` / `-IsccPath`。
- **`scripts/installer.iss`**（新增）：Inno Setup 6 每用户安装脚本。
  - `PrivilegesRequired=lowest`、`{localappdata}\Programs\拉片软件`；
  - ProgID `Lapian.Video` + `.mp4/.mov/.mkv/.webm` 的 `OpenWithProgids`；
  - `Applications\lapian.exe` + `SupportedTypes`；
  - 开始菜单/桌面快捷方式、许可目录快捷方式、卸载快捷方式；
  - 不写扩展名默认值；卸载不碰用户数据。
- **`packaging/README.txt`**（新增）：随安装包/zip 分发的运行说明、
  支持范围、用户数据位置、卸载边界、许可位置。
- **`scripts/build-release.ps1`**：新增可选 `-Package`，构建/测试/dist 后调用
  `package.ps1 -SkipBuild`；默认行为不变。
- 未改产品代码（C++/UI/解码/缓存）；未改 spec/ADR。

### 2.2 关联策略

- 只注册“打开方式”候选，不设置默认应用。卸载时删除自己的 ProgID、
  `Applications\lapian.exe`、`SupportedTypes` 与各扩展名的
  `OpenWithProgids\Lapian.Video` 值；共享键里其它应用的值保留。
- `OpenWithProgids` 的值必须是空 REG_SZ；Inno 的 `ValueType: none` 实际不创建值
  （第一版曾因此漏写，实测发现后修正）。
- `uninsdeletekeyifempty` 需放在删值条目之后；但 `.mp4` 等键通常非空
  （B 站/AppX 等已有值），所以卸载后键保留是正确行为。

### 2.3 许可与体积

- 安装包与便携 zip 都带 `licenses\` 5 个文件（LGPL-2.1/LGPL-3.0/GPL-3.0、
  THIRD-PARTY-NOTICES、SOURCE-OFFER）与根目录 `README.txt`。
- `licenses/THIRD-PARTY-NOTICES.md` 补 Inno Setup（构建期，不随包分发）。
- P12：setup 11.31MB / zip 13.65MB / 负载 32.74MB，均 ≤100MB。
- 为体积没有删任何 Qt/FFmpeg 必需 DLL；dist 仍 25 文件/32.63MB。

## 4. 口径 / 不宣称

- **F1-A1 没有通过**：本轮是热缓存、开发机、非 Explorer 真双击。正式 F1-A1
  需要冷缓存 + 基线机 + 资源管理器双击已关联的 1080p H.264 MP4。
- **不是 T7.7 全量验收**；V1–V10、P1–P14、冷缓存、DPI、基线机仍待。
- **安装器 UI 是英文**：Inno 6.7.3 自带语言无简体中文；未引入第三方翻译。
- **未签名、无应用图标**：没有代码签名证书；`lapian.exe` 无图标资源，
  快捷方式/默认程序里是通用图标。杀软误报未验证。
- **E: 工作区异常**：本机 E: 上的 exe 被套受限 token，setup 无法写
  `%TEMP%`/`%LOCALAPPDATA%`（Error 5）；复制到 C: 后正常。真实用户从
  `Downloads` 运行不会遇到。复现时必须先复制到 C:。
- **未测**：安装时 app 正在运行、跨版本覆盖/降级、卸载中途取消/重启、
  管理员全机安装、Windows 10 21H2 实机、中文向导、签名/图标。
- **Inno Setup 许可**：6.7.3 编译器提示商业用户购买许可；`license.txt`
  允许商业使用但请求商业用户购买。若项目商业分发，需评估购买（编译器
  不随包分发，不影响最终用户安装）。
- **T7.3/T7.4/T7.5 结论不变**：V10 2h/P14 未通过；4K 只是 proxy；
  可达 SMB/物理设备丢失/真实 V8 未验。

## 5. 下一步（优先）

1. **T7.7 全量验收**：需要 V1–V10 与基线机；F1-A1 用 Explorer 真双击 +
   冷缓存；安装/卸载在基线机复跑；补中文安装向导/图标/签名（若发布需要）。
2. **T7.8 基准回归脚本**：把 `--robust-test`、`--drag-test`、`--memory-test`
   固化到脚本与阈值 JSON；可把 T7.6 的打包体积/哈希检查纳入。
3. **T7.3 的 V10 2h**：拿到 V10 后按
   `scripts\soak-bench.ps1 -File <V10> -Seconds 7200 -NoLoop` 跑；
   `flags=memory_growth` 时不要写 P14 通过。
4. **安装器增强（候选，不阻塞）**：中文 `ChineseSimplified.isl`、应用图标、
   代码签名、升级/降级路径、安装时运行中进程处理。
5. **E: 限制**：如果后续还要在 E: 直接跑安装器，先确认 Windows 的
