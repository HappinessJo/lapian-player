语义/约束：

- **只索引视频流**：`session_->growing_source_for_index()` + `online_part_path_`；音频/波形走 `online_audio_source_`/`online_audio_part_path_`，绝不扫音频容器。
- **tail guard 48**：未完成时 `stable = unique - 48`；完成（EOF）后全部帧；已暴露前缀 PTS 不变才安装（MainWindow 二次校验）。
- **三态**：未完成 + 容器 duration×fps → `Estimated`；完成 → `Exact(stable)`；无容器值 → `Scanning`。不要拿 API fps/部分索引算精确总帧数。
- **seek 安装挂起**：seek worker 读同一个 `FrameIndex` 时不替换；pending 最多一份最新快照，seek 结束后补装（complete 不丢）。
- **未缓存 seek**：仍显示“缓冲中（目标帧 N）”，取消路径不变（T8.6.1a）。
- **慢增长钩子**：只用于测试，产品默认 0；在线只节流视频（音频保持正常速度）。
- **DASH 帧号数学**：容器 duration/fps；OB-2 API 29.412 vs 容器 30 的差异仍在 T8.12 定“实际 fps”口径。

## 4. 关键决定与解释

1. **保留 demux 上下文增量读**：T8.10 每 650ms `BuildOnlineIndex` 从 0 重建；慢网下累计读字节约 O(T²)。新 builder 首次打开后连续读；256KB 前沿 guard 避免 `ETIMEDOUT` 打脏 sample 状态。实测 `opens=1`、`read_ratio=1.000`。
2. **frontier 兜底重开**：大 sample 跨过 guard 时确实可能读到 `ETIMEDOUT`；用最后成功包的 `pos+size` 作为 `resume_pos`，重开 seek 到前关键帧并跳过已解析包。保证不重复/不丢帧（单测 duplicate 0、完成 5306）。
3. **快照 250ms 节流**：索引线程可以 40ms 步进追下载，但 GUI 安装最多 4 次/秒；seek 期间只存 pending，避免并发替换 `FrameIndex` 和丢 complete。
4. **三态用容器估算、索引精确**：OB-3 `estimate:5307` → `exact:5306` 是 212.261s×25 的四舍五入差 1 帧；不用 API fps 算精确。OB-2 的 29.412/30 差异仍按 T8.10 §4.7 留给 T8.12。
5. **30s 覆盖用稳定帧数衡量**：视频 VBR，字节/总字节不等于时间；OB-3 前 30s 实际约 12.7MB（18% 文件），索引在 published 12.69MB 时已覆盖 31s，读取落后 ~230KB（guard+AVIO）。
6. **波形只追加**：`WaveformGenerator::StartGrowing` 本来就是单线程顺序解码；T8.11 只加 UI 重绘（bucket 增长时），并验证早期 bucket 前缀不变。没有“每次增长重解音频”。
7. **测试节流只节流视频**：DASH 音频保持正常；波形渐进由离线 2MB/s 音频 publisher 覆盖。产品默认 `throttle=0`，发布语义不变。

## 5. 已知缺口

1. **3min 1080P30 没有直接样本**：OB-3 是 1080P**25fps**/212.261s；不把 25 写成 30。1080P30 只有 T8.10/M2 的 30fps 样本间接覆盖。
2. **波形偏移是 `av_offset` 口径**（0.525 帧），没有 OB-3 click 真值做像素级对齐；V9 click ≤1 帧沿用 T3.6 证据。
3. **慢增长是测试钩子/离线 publisher**：真实 2MB/s 网络没有长时间跑；`--online-index-test` 仅 GUI，无 headless。
4. **在线只节流视频**：音频波形渐进只在离线 case 看 bucket 增长/前缀不变。
5. **已缓存 seek** 仍限稳定前缀 + 距关键帧 ≤2s；5s GOP 点尾/任意位置 200ms 不在本任务。
6. **h264 “missing picture” stderr 噪音**：在线探针大量 FFmpeg 警告，不影响落点/总帧数/UI 数字；未定性，留 T8.13 排查。
7. **默认 AppData/Medium 未重跑**；测试根在工作区（Low integrity）。（T8.16 安装版再验）
8. **4K/1080P60/大会员未验**（T8.15）。
9. **M2 未判**；T8.12/T8.13/T8.14 未做。
