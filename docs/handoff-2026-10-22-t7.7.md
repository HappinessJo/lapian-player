### 2.2 预检脚本

新增 `scripts\t7.7-preflight.ps1`（只读清单，不跑 2h soak，不改阈值/基线）：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\t7.7-preflight.ps1 -RunCTest
```

检查项：

- 机器指纹与基线机判定（4C/8GB/iGPU/SATA SSD/Win11）；
- `dist`/setup/zip 体积与 P12；
- `baseline-dev.json` label/commit/cache_state；
- 真实 `media\acceptance\V1–V10` 规格（分辨率/编码/fps/时长/音轨/VFR）；
  V1/V3/V4 额外用 `lapian_seek_probe` 记录 KEYFRAMES/GOP；
- 合成片单 9 文件 + V8 五个 `OK=0`；
- HKCU ProgID/四扩展名 OpenWithProgids；
- 可选 `ctest`。

退出码：0=资源齐备；2=阻塞；1=脚本/基础设施错误。输出 JSON 到
`build\t7.7\preflight-<stamp>.json`。

## 3. 为什么不能继续做 T7.7

| 缺口 | 影响 |
|---|---|
| 真实 V1–V10 缺失 | F1–F8 手测、P6/P9 分类、P14 全部无法正式验收 |
| 基线机缺失 | P1–P14 的 spec 基线结论不成立；当前只有开发机预检 |
| 冷缓存未做 | F1-A1/P1/P2 仍是热缓存；不能把 T7.1/T7.8 数字当冷启动 |
| Explorer 真双击未做 | F1-A1 的入口未验收；`--file` 模拟不算 |
| 真实 V8/V5/V10 缺失 | F1-A5/VFR/P14 只有合成预检 |
| 真实显示 DPI 未做 | 只有 `QT_SCALE_FACTOR` 模拟布局 |
| 安装/关联当前未安装 | F1-A1 前要先装并确认 ProgID/OpenWithProgids |

> 资源到位后按清单顺序执行；不要用合成片单/开发机数字填正式报告。

## 4. 下一步（按优先级）

1. **等资源**：用户提供真实 V1–V10 到 `media\acceptance\`；准备 4C/8GB/集显/
   SATA SSD/Win11 基线机。先跑 `t7.7-preflight.ps1`，必须 `verdict=ready_for_t7.7`。
2. **基线机全量**：按 [T7.7 验收清单](perf/T7.7-acceptance-checklist.md) 执行
   F1–F8/P1–P14；P7 边界 2s/1s 分开记录；P10/P11 记录
   `extra_hw_frames=32` 的 iGPU 内存影响；P14 用真实 V10 跑 7200s（`-NoLoop`）。
3. **冷缓存 F1-A1**：重启 + RAMMap + Explorer 真双击；`startup-bench.ps1`
   只用于收集时序，不负责清缓存。
4. **T7.3 正式 P14**：有真实 V10 后用 `soak-bench.ps1 -Seconds 7200 -NoLoop`
   复跑；合成 V10 的 `v10-synth pass=1` 只作替身稳定性。
5. **T7.8 维护**：本轮未改阈值/基线；只有验证过的全量 run 才 `-UpdateBaseline`，
   不要用 `-Quick`。
