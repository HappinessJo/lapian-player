## 2. 本轮做了什么

### 2.1 MarkPanel 编辑区（`lapian_mark_ui`）

- [src/app/MarkPanel.h](../src/app/MarkPanel.h)/[.cpp](../src/app/MarkPanel.cpp) 底部新增 `markEditor`：
  - `QLineEdit markLabelEdit`（标签，回车保存，带清空按钮）；
  - `QPlainTextEdit markNoteEdit`（备注，88px，`Ctrl+Enter` 保存、`Enter` 换行、`Tab` 移焦）；
  - `markEditorTitle` 显示“编辑 · 帧 N”。
- 选中行才显示编辑区；`SelectMark`/`SelectNearFrame`/`currentItemChanged` 载入对应标记；切换选中前先提交旧编辑。
- 提交时机：标签 Enter、备注 Ctrl+Enter、编辑框失焦、切换选中、`SetMarks` 前、切文件、关窗、增删标记前。日常键入不写盘。
- 提交后只更新当前行标签/备注摘要（`UpdateMarkText`），不 `Rebuild()`、不改选中与滚动位置；`QTreeWidgetItem` 指针保持不变（单测断言）。
- 标签保存前 `trim()`；空标签按空串存储，列表显示回退名“帧 N”；备注允许为空、保留多行纯文本。
- 删除保护：编辑框聚焦时 `Delete` 不删除标记（`IsEditorFocused` + `ShortcutOverride` 双保险）。
- `SetMarks` 会先 `FlushEditor()`；这样增删/重开导致的整表刷新不会吞掉尚未失焦的文本。

### 2.2 MainWindow 接入

- 连接 `MarkPanel::markTextEdited(id,label,note)` → `ApplyMarkTextEdited`：
  1. 内容与 `MarkStore` 相同则直接返回（失焦未改动不写盘）；
  2. `MarkStore::SetMarkText`（T5.1 已有，更新 `updated_at`）；
  3. `marks_dirty_ = true`；`mark_panel_->UpdateMarkText` 只改一行；
  4. `SaveMarks(true)` 立即原子写；失败走既有的 `ShowMarkSaveFailure`，内存修改不丢。
- `FlushMarkEditor()` 接到：`FlushMarksBeforeSwitch()`、`FlushMarksOnClose()`、`ApplyAddMark()`、`ApplyDeleteMark()`。
  - `closeEvent` → `FlushMarksOnClose` → 先 flush 编辑框再判断 `marks_dirty_`；这是 F8-A2 的真正路径。
- 焦点隔离（spec §3.7）：
  - `MarkPanel::eventFilter` 在标签/备注框上接受除 `Esc` 外的 `ShortcutOverride`，Space/W/M/I/O/L/Ctrl+M/Ctrl+G/Ctrl+O/Delete 等不会落到全局 QAction；
  - `MainWindow::TogglePlayback`（Space）、`ShowGotoDialog`（Ctrl+G）、`OpenDialog`（Ctrl+O）新增 `IsTextInputFocused()` 让位；`ToggleWaveform`（W）让位时用 `QSignalBlocker` 恢复勾选，避免 `toggled` 递归；
  - 既有的循环/速度/缩放/静音/添加标记让位保持不变；`DeleteCurrent` 在编辑框聚焦时 return。
- `Esc` 不拦截：留给后续全屏退出的全局语义；当前无全屏，编辑框内 Esc 无动作。

### 2.3 自动化入口

`main.cpp` 新增 `--note-test`（配合 `--file A --file-b B`），设置 `LAPIAN_MARK_LOG`，末尾按失败数返回退出码。序列：

## 4. 口径与决策

1. **“回车保存”与多行备注的歧义（已记录，未静默改 spec）**：
   - 标签 `Enter` 保存；
   - 备注 `Enter` 换行、`Ctrl+Enter` 保存；
   - 失焦/切换标记/切文件/关窗都保存。
   spec §3.6 的“回车即时保存”在备注上收窄为 Ctrl+Enter；若以后要改成备注 Enter 保存，则备注只能单行，需走 spec §9 版本记录。
2. **不防抖**：只在明确的提交事件写盘；键入不写。每次提交一次原子写；20 次 p95 7.38ms，无需 200–300ms 防抖。
3. **标签 trim、空标签回退显示**：见 §2.1；存储不自动填“帧 N”（只有新建标记时 `MarkStore::AddMark` 会填默认标签）。
4. **不改 schema / 不加保存按钮 / 不做导出**：沿用 T5.1 sidecar 与 `SetMarkText`。

## 5. 缺口 / 不宣称

1. **真人键盘/输入法未手测**：自动化是程序化输入与 `sendEvent`；中文 IME 组字、AltGr、真实窗口焦点切换仍留 T6.2/F7 手测矩阵。
2. **F6-A8 不是正式 P9**：V9 1080p 短 GOP 数字不能外推全素材/基线机/4K。
3. **F4-A2 长 GOP 未改善**：proxy-V1 B→A 148–157ms 仍在 T7；T5.3 未在长 GOP 上测备注/标记点击。
4. **AppData 回退编辑端到端未重测**：T5.1 已 ACL 验证存储回退；T5.3 只在可写目录跑编辑保存。
5. **关窗保存失败分支未自动化**：没有构造不可写盘来触发“仍要退出吗？”与备注 flush 的组合；代码路径与 T5.2 相同。
6. **编辑器布局/DPI 未验收**：固定 88px 高、侧栏 300px；T6.4 再评估 DPI 与分隔条。
7. **列表内联编辑未做**：编辑只在底部详情区，不是验收要求。
