## 2. 本轮做了什么

### 2.1 新增 `lapian_settings`

- [src/core/AppSettings.h](../src/core/AppSettings.h)/[.cpp](../src/core/AppSettings.cpp)：
  - `AppSettings { int volume; bool waveform_visible; }`，默认 `100 / true`。
  - `ParseAppSettings(QByteArray)` / `SerializeAppSettings` 为纯函数，只依赖 Qt Core；
    单测不链接 Qt Widgets。
  - `SettingsStore`：默认根 `%APPDATA%\拉片软件`（与 MarkStore 的 AppData 父目录一致），
    文件 `<root>/settings.json`；`Load()` / `Save()`；`QSaveFile` 原子写；
    读取上限 64 KiB。
  - JSON：`{"schema":1,"volume":55,"waveform":false}`；UTF-8、带 schema。
- [src/CMakeLists.txt](../src/CMakeLists.txt)：新增 `lapian_settings` 静态库，`lapian` 链接。
- [tests/app_settings_test.cpp](../tests/app_settings_test.cpp)：默认值、roundtrip、clamp
  （含 `1e300`/`1e-300`）、非法类型、损坏 JSON、缺 schema、未来 schema、未知键、
  Unicode 路径、原子覆盖写、目录占用/不可建目录的静默失败。新增 `ctest` 第 18 项。

### 2.2 MainWindow 接入

- [src/app/MainWindow.h](../src/app/MainWindow.h)/[.cpp](../src/app/MainWindow.cpp)：
  - 构造函数新增可选 `settings_root`（测试注入目录；空则默认 `%APPDATA%`）。
  - UI 构造完成后、`ShowEmptyState()`/首个文件打开前调用 `LoadSettingsIntoUi()`：
    读文件 → `ApplySettings` 走真实的 `volume_slider_->setValue` 与
    `waveform_action_->setChecked`，同步 `volume_`/`waveform_visible_`/tooltip/时间轴波形带。
    `applying_settings_` 防止应用期间触发保存。
  - `OnVolumeChanged` 与 `ToggleWaveform` 末尾 `ScheduleSettingsSave()`：
    250ms 单次去抖；`FlushSettings()` 用 `QSaveFile` 落盘。
  - `closeEvent` 最先 `FlushSettings()`，**不塞进** `SnapshotService::Drain` 的等待链；
    析构再 flush 一次。保存失败保留 dirty、静默、不阻止关窗。
  - 只写 `volume` 与 `waveform`；`loop_`/`rate_`/`muted_`/窗口几何/最近文件都不写。
- 测试入口：`SetVolumeForTest`、`SetWaveformVisibleForTest`、`FlushSettingsForTest`、
  `ReloadSettingsForTest`、`SettingsPathForTest`、`SettingsStateForTest`、
  `SettingsLoadStatusForTest`、`DefaultSettingsRootForTest`、`LastSettingsSaveMsForTest`、
  `LastSettingsLoadMsForTest`。

### 2.3 测试入口

[src/app/main.cpp](../src/app/main.cpp)：

- `--settings-path <dir>`：注入设置根（目录；放进构造参数，Unicode 安全，不走 qputenv）。
- `--settings-test`：要求同时给 `--file`；先删除该根下的 `settings.json`，再在一个进程内验证
  默认/写读/关窗保存/损坏/非法/未知键/未来 schema/目录占用/循环与速度不落盘，并用 20 次
  保存统计延迟；最后留下 `volume=55, waveform=0`。
- `--settings-expect <volume> <waveform>`：第二次进程只验证恢复（F8-A1）以及
  `loop=0`、`speed=1`；不改设置。
- 两个入口都自动设置 `LAPIAN_SETTINGS_LOG=1`（仅 stderr 日志）；未给 `--settings-path` 时
  默认用 `build\t6.3-settings`，不碰用户配置。

## 4. 决策与口径

1. **只持久化两个键**：`volume` 与 `waveform_visible`。循环、速度、静音、窗口几何、最近
   文件都不写；phase 2 有循环/速度断言。
2. **JSON + schema，不用 QSettings/注册表**：便于审查、原子写、未知键忽略；默认根
   `%APPDATA%\拉片软件\settings.json`，与 sidecar 回退的父目录一致。
3. **逐项回退**：文件缺失/空文件 → `missing`；JSON 坏/非对象/缺 schema/非整数 schema →
   `corrupt`；整数 schema≠1 → `unsupported_schema`；三者都用默认值。字段类型不对保留默认；
   音量先范围截断再四舍五入，避免 `1e300` 溢出；未知键忽略。
4. **原子写 + 静默失败**：`QSaveFile`（`setDirectWriteFallback(false)`）；目录不可建、打开、
   写、commit 任一失败返回 false，旧文件保留，dirty 保留，不弹错误、不阻止关窗。
5. **保存时机**：音量/波形变更 250ms 去抖 + 关窗/析构 flush；关闭路径在 `Drain` 之前独立
   执行，不进入截图等待链。
6. **应用时机**：UI 构造完成后、首个文件打开前同步读；文件上限 64 KiB，实测 <1ms。
   不是冷启动 P1/P2 验收；P1/P2 仍归 T7.1。
7. **损坏不备份**：与 MarkStore 的 `.bak` 不同；设置文件损坏时本次回退默认，下次变更覆盖。
   spec 未要求设置备份，不新增用户可见行为。
8. **未来 schema 回退默认**：不猜测新字段；当前没有迁移逻辑。若以后加字段，按 spec §9
   版本记录升级 schema，并补迁移单测。

## 5. 缺口 / 不宣称

1. **真实 `%APPDATA%` 写入未验证**：本会话执行环境拒绝非系统进程写 AppData；重定向 `APPDATA` 的跨进程 F8-A1 不能
   替代真实用户配置目录手测。不要把本文件当成“真实重启已通过”。
2. **不是基线机/冷启动验收**：开发机 RTX 4060、1920×1080@100%；P1/P2 未测。
3. **不是真人操作**：音量/波形由测试入口改控件；真实鼠标拖音量、W 键、关窗按钮仍需手测。
4. **无多实例锁**：两个实例同时改设置时后写覆盖；首期与 MarkStore 一样不加锁。
5. **无权限场景用“目录占用/不可建目录”模拟**：没有构造真实 ACL 只读文件；真实只读
   `%APPDATA%` 的静默失败仍需环境验证。
6. **没有设置迁移**：schema 2 及以上整份回退默认；首次加字段时要补迁移与单测。
7. **音量滑块连续拖动只落盘一次**：250ms 去抖；如果进程在 250ms 内被强杀，最后一次变更
   可能丢失。正常关窗/析构会 flush；崩溃恢复不在首期。
