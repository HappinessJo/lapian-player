## 2. 本轮做了什么

### 2.1 全屏入口与退出

- [src/app/MainWindow.cpp](../src/app/MainWindow.cpp)：
  - `F` QAction（`WindowShortcut`）→ `ToggleFullScreen()`；双击画面经 GfxWidget 信号走同一入口。
  - `Esc` QAction（`WindowShortcut`）→ `ExitFullScreen()`；**只在“全屏且没有文本输入焦点”时启用**，并监听 `QApplication::focusChanged` 实时更新。
  - `MainWindow::keyPressEvent` 兜底：Esc 快捷键被禁用时（例如备注框聚焦），按键沿父链传上来，仍先检查 `IsTextInputFocused()`，不在备注框里退全屏。
  - `ToggleFullScreen` 自身也先检查 `IsTextInputFocused()`：F 与双击都不会在备注/帧号输入中间抢焦点。
- [src/app/GfxWidget.cpp](../src/app/GfxWidget.cpp)：新增 `mouseDoubleClickEvent` → `fullScreenToggleRequested()`；只处理左键双击，单击/焦点/拖动路径不变。
- `EnterFullScreen()`：
  - 先保存 `saveGeometry()`、`isMaximized()`、当前焦点控件（`QPointer`）；
  - `showFullScreen()`；把焦点还给进入前的控件；状态栏提示“已进入全屏：F / Esc 退出”。
- `ExitFullScreen()`：
  - 进入前是最大化 → `showMaximized()`；否则 `showNormal()` + `restoreGeometry()`；
  - 优先恢复退出前的焦点，其次恢复进入前的焦点；状态栏提示“已退出全屏”。
- **布局不改**：时间轴、信息栏、右侧标记侧栏、状态栏在全屏下都保留。F1-A6 只要求“画面比例不变、时间轴与帧号仍可用”，隐藏侧栏属于未定义的交互扩张，留作后续需求。

### 2.2 交换链跟随 resize

- 交换链仍由 `GfxWidget::resizeEvent → UpdateSwapChainSize()` 驱动，尺寸 = 控件逻辑尺寸 × `devicePixelRatioF()`；`Resize`/`Present` 继续走 `D3D11ContextMutex` 递归锁，没有绕开截图回读。
- 新增 `GfxWidget::swapChainSize()` 只读访问器，供自动化确认“交换链尺寸 == 控件 × DPR”；未初始化/设备丢失返回空。
- 全屏 1080p 实测 980×531 → 1620×891，交换链同步；1080p→4K 只换视频纹理，交换链保持 1620×891。

### 2.3 截图队列 Drain 竞态修复（T6.1 暴露）

- [src/app/SnapshotService.cpp](../src/app/SnapshotService.cpp)：工作线程原先先置 `busy_=false` 再 `emit snapshotSaved`，`Drain()` 可能在信号入队前返回；4K 全屏测试因此偶发读到空路径。
- 现在**先 emit 信号，再清 `busy_`/通知 idle**。`Drain()` 返回时信号已投递到接收线程队列，调用方 `processEvents` 后必然拿到结果；切文件/关窗路径也更确定。
- 队列上限、编码/写盘/目录回退、D3D11 回读锁均未改。

### 2.4 自动化

`src/app/main.cpp` 新增 `--fullscreen-test`（可配 `--file A --file-b 4K`，复用 `--snapshot-pictures`）：

1. 普通窗口记录 geometry / GfxWidget / 交换链，帧 100；
2. 真实 `F` 按键进入全屏：窗口覆盖屏幕、GfxWidget 变大、交换链 = 控件 × DPR、时间轴/信息栏可见、帧号 100；
3. 全屏中点击时间轴中点：目标帧 60、画面/帧号/播放头到 60、保持暂停；
4. 全屏中 `S`：PNG 1920×1080、保存帧 == 显示帧；
5. 备注框聚焦后按 `F`/`S`/`Esc`：不切全屏、不截图、不退出、焦点不丢；
6. `F` 退出：几何恢复、GfxWidget/交换链恢复、焦点仍是 GfxWidget；
7. `F` 再进/再出、双击进/双击出；
8. 退出后 `Space` 播放/暂停；
9. 全屏中切 4K：帧 60、PNG 3840×2160、交换链不变、`Esc` 退出；
10. 最大化状态下进/出全屏，确认回到最大化。

测试入口（`MainWindow`）：`ToggleFullScreenForTest`、`PressFullScreenKeyForTest`、`PressEscapeKeyForTest`、`PressSpaceKeyForTest`、`FocusVideoForTest`、`DoubleClickVideoForTest`、`IsFullScreenForTest`、`IsMaximizedForTest`、`IsPlayingForTest`、`FullScreenStateForTest`、`GfxWidgetSizeForTest`、`SwapChainSizeForTest`、`TimelineSizeForTest`、`TimelineFrameAtForTest`、`ClickTimelineForTest`、`InfoFrameTextForTest`、`FocusWidgetNameForTest`、`IsTextInputFocusedForTest`、`TimelineVisibleForTest`、`InfoBarVisibleForTest`、`CurrentFrameForTest`、`LastFullScreenToggleMsForTest`。

## 4. 决策与口径

1. **全屏不隐藏任何面板**：spec §3.1 只要求时间轴/帧号仍可用；隐藏侧栏会改变 T5.2/T5.3 的编辑与焦点路径，需求未定义。若以后要“沉浸式全屏”，另立任务并走 spec 版本记录。
2. **Esc 的优先级**：编辑框聚焦时 Esc 仍归文本框（T5.3 决策），因此 Esc QAction 只在“全屏 + 非文本焦点”启用，handler 再检查一次；这样 Esc 不会被全屏逻辑吞掉，也不会在备注框里退全屏。
3. **F/双击与文本框**：F 是新的全局快捷键，MarkPanel 的 `ShortcutOverride` 已按“除 Esc/Enter 外全部接受”覆盖它；MainWindow 入口再检查 `IsTextInputFocused()`，双重保险。
4. **双击不吞单击**：只在 `mouseDoubleClickEvent` 里发信号；GfxWidget 没有单击拖动逻辑，时间轴拖动完全不受影响。
5. **几何/状态恢复**：进入前保存普通 geometry 与最大化标志；退出时最大化回最大化，普通窗口回 `restoreGeometry`。焦点优先恢复到退出前控件，其次进入前控件。
6. **交换链不重建设备**：全屏只触发 `ResizeBuffers`；1080p→4K 只换纹理。所有 D3D11 立即上下文操作仍在 `D3D11ContextMutex` 下，与截图回读串行。
7. **Drain 语义收紧**：先发 saved/failed 信号再置 idle，使 `Drain()+processEvents` 可确定拿到结果；不改变编码/写盘顺序与错误处理。

## 5. 缺口 / 不宣称

1. **F1-A6 只有自动化**：所有按键/双击/时间轴点击都是程序化事件，没有物理键盘/鼠标与真人观看；`QWidget::grab()` 抓不到 D3D11 原生 HWND，视频区截图是黑的（布局截图只证明 UI 未被裁切）。
2. **不是正式 V1/V4/V5 验收**：1080p 素材是 V9 副本，4K 是 V9 放大的合成片；真实 V4 4K、V5 竖屏没有跑。
3. **不是基线机**：开发机 RTX 4060 / 1920×1080 @100%；没有 4C/8G/集显基线机数字，`toggle_ms` 不能当 P1/P9/P11。
4. **DPI/多显示器未覆盖**：150%/200% 缩放、跨屏全屏、不同刷新率留给 T6.4；本轮的 DPR 固定 1.00。
5. **播放中切换全屏未单独测**：本轮全屏进入/退出都在暂停状态；播放不中断由 T5.4 的播放中截图与 T6.1 的退出后 Space 间接覆盖，没有统计全屏切换瞬间的掉帧/underrun。
6. **全屏内 Ctrl+G 对话框/Esc 关对话框未测**：依赖模态窗口的快捷键语义；T6.2 的键位矩阵应覆盖。
7. **VFR/10-bit/长 GOP 全屏未测**：截图/渲染路径本身未改，但没有端到端证据。
8. **真实图片目录回退、ACL 只读目录**仍是 T5.4 缺口；本轮回归用的是注入的图片根与同名文件阻塞。
9. **F7 键位矩阵未做**：T6.1 只验证了 F/Esc/Space/S 在全屏相关路径上的行为；完整矩阵属于 T6.2。
