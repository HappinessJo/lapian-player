## 3. 验证结果

### V9

- 音频首包 PTS `-0.021333s`，`Skip Samples=1024` → priming 21.333ms；
- `av_offset_us = 0`，`AV_OFFSET_ESTIMATED=1`；
- V9 click 峰值 **4.169s**，第 100 帧 **4.1667s**，偏差 **2.3ms ≈ 0.055 帧**。

### 非零 offset

本地生成 `build/offset100.mp4`（音频名义后移 100ms）→ `AV_OFFSET_US=78000`。容器 copy/edit list 会把名义 100ms 量化成 78ms；只用于证明非零偏移被识别。

- `media_probe_test`：V9 offset 可用且 ≤1 帧。
- `audio_test`：V9 click 峰值在 frame100 ±1 帧。

## 4. 关键实现地图

| 文件 | 作用 |
|---|---|
| [src/media/MediaInfo.h](../src/media/MediaInfo.h) | `av_offset_us`、`av_offset_estimated` |
| [src/media/MediaProbe.cpp](../src/media/MediaProbe.cpp) | 首包 PTS + skip_samples 采样、offset 估算 |
| [src/audio/AudioEngine.*](../src/audio/AudioEngine.h) | `Open(..., av_offset_seconds)`；起播 seek `target + offset` |
| [src/app/MainWindow.cpp](../src/app/MainWindow.cpp) | 把 `info.av_offset_us` 传给音频引擎 |
| [tests/audio_test.cpp](../tests/audio_test.cpp) | V9 click 在 frame100 ±1 帧 |
| [tests/media_probe_test.cpp](../tests/media_probe_test.cpp) | V9 offset 断言 |

行为要点：

- offset 只估一次，运行中不动态补偿。
- 音频时钟锚点仍是视频媒体时间；offset 只影响 seek 到音频时间轴的哪个位置。
- 波形映射的约定：bucket 存音频时间轴，显示时减 offset 再进帧格；T3.5/T3.6 实现。

## 5. 已知缺口

1. **波形映射未实现**：T3.5/T3.6。
2. **正式 V1 未就位**：V9 是合成片。
3. **offset 只来自首包/首个 skip samples**：不是完整 edit list 重建；复杂容器仍可能差几十 ms。
4. **synthetic 100ms 片测得 78ms**：不是精度指标。
5. **10min/基线机/4K 未测**。
6. **动态 A/V 偏移**不做，符合 spec。
7. **T3.3 的听感/循环重置**仍未验收；T4.2 做循环。
