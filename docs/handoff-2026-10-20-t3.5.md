## 4. 关键实现地图

| 文件 | 作用 |
|---|---|
| [src/audio/WaveformData.*](../src/audio/WaveformData.h) | 200/s bucket、min/max、offset、线程安全读写 |
| [src/audio/WaveformGenerator.*](../src/audio/WaveformGenerator.h) | 独立线程 + `AudioDecoder` 48k 单声道、进度/取消/状态 |
| [src/app/MainWindow.*](../src/app/MainWindow.cpp) | 文件打开时启动/取消、状态栏进度 |
| [src/tools/waveform_probe/main.cpp](../src/tools/waveform_probe/main.cpp) | 控制台 P13 探针，不入分发 |
| [tests/waveform_test.cpp](../tests/waveform_test.cpp) | 数据边界 + V9 生成/峰值 bucket |

数据约定：

- bucket 时间轴是**音频时间**；显示时用 `offset_seconds`（T3.4）映射到视频帧格。
- V9/proxy offset 为 0；非零 offset 文件（本地 synthetic +78ms）会整体平移波形。
- 生成只读文件，不写 sidecar/源视频。

## 5. 已知缺口

1. **没有波形绘制**：T3.6 才画到时间轴，含 W 开关、缩放/滚动、VFR 聚合、无音频空态。
2. **P13 是开发机单样本**：不是基线机；2h/V10 未跑。
3. **未测播放+生成的 CPU 干扰**：独立线程，但没有 1080p 播放 + 10min 波形的同机测量。
4. **VFR 未验**：生成按音频 PTS 存桶；VFR 的 bucket→frame 聚合在 T3.6。
5. **正式 V1/V6 未就位**；V9/V5 仍需手测。
6. **无音轨空态只在状态栏**；波形区文本随 T3.6。
7. **取消耗时未单独测**：切文件/关窗会 join，但大文件中途 cancel 的延迟没有数字。
