## 1. 实现内容

- `VideoDecoder`：打开本地文件，选视频流；优先 D3D11VA，硬件设备/解码器打开失败自动回退软解。
- `DecodeFirstFrame()`：seek 到流起点，解码首帧；硬件首帧失败会重开软解再试一次。
- `DecodeNextFrame()`：继续顺序解码；供 T1.5 播放/调度使用。
- `DecodedFrameInfo`：尺寸、pix_fmt、位深、PTS、帧时长、关键帧、是否硬解帧、`AVFrame*`（由解码器持有）。
- `HardwareActive()`：硬件路径是否配置成功；**实际帧是否硬解**看 `DecodedFrameInfo.hardware`。
- 10-bit：`BitDepth()`/`IsHighBitDepth()` 来自 `codecpar`/pix_fmt；D3D11 不支持时静默走软解，不崩溃。
- **T1.3 共享设备**：`OpenWithD3D11Device()` 让硬解帧与渲染器同属一个 `ID3D11Device`；外接设备在 hwdevice 释放路径补了 `AddRef`，跨设备硬件帧在渲染器侧会拒绝并回退 CPU。

## 4. 复现

```powershell
# 硬解首帧（默认）
build\release\bin\lapian_decode_probe.exe --file media\V9.mp4 --frames 3

# 软解
build\release\bin\lapian_decode_probe.exe --file media\V9.mp4 --frames 3 --sw

# 10-bit 合成片
ffmpeg -f lavfi -i testsrc2=size=320x240:rate=24:duration=1 -c:v libx264 `
  -pix_fmt yuv420p10le -profile:v high10 build\test-media\10bit.mp4
build\release\bin\lapian_decode_probe.exe --file build\test-media\10bit.mp4 --frames 1
```
