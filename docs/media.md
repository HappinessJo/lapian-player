# 验收素材与测量口径（T0.2）

> 素材本身不入库（`media/` 已 gitignore）。本文件是片单、命名、来源与用途的唯一说明。
> 性能验收以 spec §4.1 + §8 为准；本文件只定义“用哪个文件测哪一项”。

## 1. 目录约定

```
media/
  V1.mp4     1080p H.264 24fps，3–10 分钟，带音乐
  V2.mp4     1080p H.264 30fps
  V3.mp4     1080p HEVC 60fps
  V4.mp4     4K H.264 30fps
  V5.mp4     VFR 手机录屏（含旋转元数据更好）
  V6.mp4     10 分钟以上 1080p
  V7.mp4     无音轨视频
  V8.bin     损坏或不支持的文件（或任意非视频文件改名）
  V9.mp4     T0.2 合成：1080p24，第 100 帧 click + 一帧白闪
  V10.mp4    2 小时 1080p
```

- 文件可直接用真实参考片，按上表改名/覆盖即可；子目录不限。
- `scripts\asset\make-v9.ps1` 可本地合成 V9（不联网运行，仅构建期下载编码器）。
- 若素材未就位，`scripts\asset\make-proxies.ps1` 可生成 V1/V3/V4 的**代理素材**
  （短时长、指定 GOP），只用于验证探针与工具链，**不得用于 P6/P7 的正式结论**。

## 3. V9 合成规格（`scripts\asset\make-v9.ps1`）

| 项 | 值 |
|---|---|
| 分辨率/帧率 | 1920×1080，24fps CFR |
| 时长 | 5 秒（120 帧，0–119） |
| 画面 | 全黑；第 100 帧整帧纯白（110ms 处），其余帧黑 |
| 音频 | 48kHz 单声道 AAC；1080Hz 短促 click 约 10ms，起点对齐第 100 帧 PTS（4.1667s） |
| 容器 | MP4 |
| 校验 | 解码第 99/100/101 帧取中心像素：黑/白/黑；音频包 PTS 与第 100 帧 PTS 差 ≤1ms |

> 编码器只用于**生成素材**，不随产品分发；产品仍是 LGPL 最小构建。

## 4. 测量口径（与 spec §4.1 对齐）

- **P1 冷启动到窗口可交互**：进程创建 → 主窗口句柄可用且消息循环响应；重启后首次启动、目标文件不在 OS 缓存（T7.1 正式口径）。
- **P2 双击已关联文件到首帧**：双击 → 首帧呈现；需要 T1.4 文件关联与 T1.2 首帧解码，T0.2 只留脚本入口。
- **P5 拖动停顿**：呈现时间戳 + UI 心跳，画面无更新且 UI 无响应 >200ms 记一次；T0.2 先提供 UI 心跳采样。
- **P10 空闲**：打开 V1 并暂停 60s 的 working set；另报空态基线。
- **P7/P8**：P7 = ±1 帧步进（PgUp/PgDn/方向键，热解码器+缓存）；P8 = 同方向长按（解码器热），每帧呈现。
- **P6/P9**：P6 用产品拖动路径；P9 冷随机跳转；均记录目标帧距前关键帧的距离，只有 ≤2s 的样本计入保证档；长 GOP 单列。
- **GOP**：正式 V1/V3/V4 到位后，用 `lapian_seek_probe` 记录实际 GOP/关键帧间隔；不要用代理素材替代正式结论。
- 统计：同一操作 20 次，p95 = 至少 19 次达标；报告记录 p50/p95。

## 5. 代理素材（仅工具验证）

`scripts\asset\make-proxies.ps1` 生成：

| 代理 | 规格 | 用途 |
|---|---|---|
| proxy-V1 | 1080p H.264 24fps，30s，GOP 250（≈10s） | 长 GOP 精确 seek 探针 |
| proxy-V3 | 1080p HEVC 60fps，20s，GOP 120 | HEVC 硬解/步进探针 |
| proxy-V4 | 4K H.264 30fps，15s，GOP 60 | 4K seek/内存探针 |

代理只回答“物理成本量级”，不替代 V1/V3/V4 的 Go/No-Go 结论；报告中必须标注素材类型。
