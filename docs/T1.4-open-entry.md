# T1.4 打开入口与错误处理验证记录

- **日期**：2026-10-19
- **任务**：[tasks.md](../tasks.md) M1 / T1.4
- **状态**：打开入口、空态、错误提示、失败保留旧会话、首帧停第 0 帧完成；拖拽与 Ctrl+O 已接，拖拽只做了代码路径，未做自动化 UI 测试。
- **范围**：Ctrl+O、拖拽、命令行/关联路径；一次一个文件；打开后停首帧；VFR 初判提示；错误可读。不做播放、时间轴、标记保存。

## 1. 实现

- `MediaSession`：探测 + 解码器 + 首帧；`Open()` 成功才替换旧会话，失败保留旧画面；`last_attempt()` 保留失败探测分类给 UI。
- `MainWindow`：
  - `Ctrl+O` → `QFileDialog`，过滤器 MP4/MOV/MKV/WebM。
  - 拖入本地文件 → `OpenFile()`；非本地 URL 不接收。
  - `lapian.exe <path>` 与 `lapian.exe --file <path>` 都支持（系统文件关联走第一个参数）。
  - 空态：深灰画面 + 状态栏“将视频拖到这里，或按 Ctrl+O 打开”。
  - 打开成功：标题为文件名，状态栏显示分辨率/帧率/硬软解/第 0 帧；VFR 初判时追加 `VFR` 并提示 8 秒。
  - 错误：按 `MediaProbeError` 转中文，再附技术细节；`QMessageBox` 可读，进程不退出。
  - 新文件成功前调用占位 `SaveCurrentStatePlaceholder()`；T6 接入 sidecar 后替换。
- 首帧仍走 T1.3 的 `GfxWidget::SetVideoFrame`；解码器与会话保留，T1.5 可直接继续解码。
