## 2. 本轮做了什么

### 2.1 步进/首末帧提升为窗口级

- [src/app/MainWindow.h](../src/app/MainWindow.h)/[.cpp](../src/app/MainWindow.cpp)：
  - `eventFilter` 安装在 `qApp` 上，统一处理 `PgUp/PgDn/←/→/Home/End`。
  - 一个连发源：首次立即走 1 帧，300ms 后每 70ms 一帧；`step_repeat_timer_` 为 `PreciseTimer`。
  - 忽略 OS 自动重复：`QKeyEvent::isAutoRepeat()` 的 KeyPress 只吞掉，不额外走帧。
  - 停止条件：松开键、`QApplication::focusChanged`、`QEvent::WindowDeactivate`、应用失活、到达首/末帧（避免对同一帧反复 seek）。
  - 焦点在视频、时间轴（NoFocus）、侧栏标记树、音量滑块、无焦点时都可用；不再要求 GfxWidget 有焦点。
- [src/app/GfxWidget.cpp](../src/app/GfxWidget.cpp)/[.h](../src/app/GfxWidget.h)：删除 `stepRequested` 信号、`step_timer_`、`step_direction_`、`step_repeat_started_`、`keyReleaseEvent`、`focusOutEvent` 与 keyPress 里的步进分支；只保留 Space/Ctrl+G 的本地兜底（QAction 主路径仍先触发，无双触发）。
- 到达边界时停止连发：旧实现会在边界继续 seek 同一帧，新实现直接停，减少无意义解码。

### 2.2 Home / End

- 之前没有入口。现在 `Home` 跳 0，`End` 跳索引末帧（`index().size()-1`），走 `GoToFrame`（会暂停播放、同步帧号/时间轴/画面）。
- 索引未就绪时 `CanStepFrames()` 为 false，按键不被吞掉（交给控件）；当前架构在 `OpenFile` 时索引已就绪，T2.2 的三态仍未改。

### 2.3 `+` / `-`

- 旧 QAction 快捷键在 V9（120 帧）上看起来失效，实际是 fit 缩放（8.167px/帧）已超过 8px/帧上限，`+-` 被 clamp 成 no-op；换 60s 素材后才验证出来。
- 现由事件过滤器统一处理：`Qt::Key_Plus`、`Qt::Key_Equal + Shift`（少数布局）、numpad `+`、`Qt::Key_Minus`。
- `zoom_in_action_` / `zoom_out_action_` 不再注册 QAction 快捷键，只保留 enabled 状态供过滤器判断；`ShortcutMapForTest` 里 `zoom_in=+ zoom_out=-` 是过滤器绑定，不是 QAction。
- 文本框内 `+`/`-` 仍归文本；AltGr（Ctrl+Alt）不触发；模态窗口不触发。

### 2.4 文本/模态让位

- 文本：`IsTextInputFocused()`（QLineEdit/QTextEdit/QPlainTextEdit）为真时，步进/Home/End/`+`/`-` 都不处理；方向键、Home/End、空格、`+`/`-` 归编辑器。
- 模态：`QApplication::activeModalWidget()`/`activePopupWidget()` 非空时不处理；QInputDialog 的帧号输入、QMessageBox 删除确认都覆盖。
- Esc/Enter 的 T5.3/T6.1 语义不变：备注框内 Esc 不退全屏；F/S/W/M 等在编辑框内作为文本。
- `Ctrl+O` 的文件对话框是原生模态窗口，自动化只验证 shortcut 映射；真实打开走 T1.4 手测。

## 4. 决策与口径

1. **全局键只对文本框/模态让位**：spec §3.7 只豁免文本框，所以标记树有焦点时 Home/End/方向/翻页也走帧步进。标记树的键盘导航因此让位；鼠标选择、点击跳转与 `Delete` 保留。若以后要恢复列表键盘导航，需要先改 spec 的焦点口径或另立任务；不要在 T6.3/T6.4 偷偷改。
2. **一个连发源**：不再保留 GfxWidget 的第二个定时器；QAction 和事件过滤器不能同时处理同一个步进键。
3. **`+`/`-` 不注册 QAction 快捷键**：事件过滤器单源，避免布局/Qt 版本造成双触发；ShortcutMap 仍报告 `+`/`-`。
4. **Esc 优先级不变**：T6.1 的 Esc QAction 只在全屏且非文本焦点启用；T6.2 没改这条。
5. **AltGr 不误判**：带 Ctrl/Alt/Meta 的键不进步进/缩放分支；中文输入法与 AltGr 仍需真人手测。
6. **边界停止**：到达首/末帧时停止连发，不重复 seek 同一帧；比旧实现更省，但长按到边界会停住而不是持续尝试。

## 5. 缺口 / 不宣称

1. **不是真人键盘验收**：所有键都是程序化 `QKeyEvent`；中文输入法、AltGr、不同键盘布局、物理长按没有真人测试。
2. **`Ctrl+O` 原生文件对话框未自动化**：只验证 shortcut 映射；真实打开/取消走 T1.4 手测。
3. **标记树键盘导航已让位**：这是 spec 口径下的取舍，不是 bug；见 §4.1。
4. **不是基线机/DPI 验收**：开发机 1920×1080 @100%；150%/200%、多显示器留给 T6.4。
5. **F7 没有编号 F7-A 条款**：验收是 §3.7 表 + 文本框两条规则；真人 F7 矩阵仍要按 tasks.md 走查一次。
6. **全屏中 Ctrl+G 对话框/Esc 关对话框**：T6.2 的 Ctrl+G 在普通窗口测；全屏 + 对话框组合留给 F7 手测。
7. **音频/播放交互**：Space 播放/暂停、长按暂停都由 `GoToFrame` 暂停播放覆盖；没有测“播放中长按步进”的音频 underrun（T7 范围）。
