## 2. 本轮做了什么

### 2.1 标记侧栏（新库 `lapian_mark_ui`）

- 新增 [src/app/MarkPanel.h](../src/app/MarkPanel.h)、[src/app/MarkPanel.cpp](../src/app/MarkPanel.cpp)。
- `QTreeWidget` 三列：帧号 / 标签 / 备注摘要；默认标签“帧 N”，备注为空（T5.3 接编辑）。
- 点击行发 `markActivated(id, frame)`；`Delete` 键（`QTreeWidget` 或子控件聚焦时）与右键菜单“删除标记…”发 `deleteRequested(id)`；右键“跳到该帧”。
- 侧栏顶部显示标记数、存储位置（`sidecar` 或“%APPDATA% 回退”，未落盘标“未写入”）、警告条；完整路径在 tooltip。
- 空态“还没有标记 / Ctrl+M 在当前帧添加”；列表 `uniformRowHeights`，100 行重建 p95 0.335ms。
- 自定义 `QWidget` 需要 `WA_StyledBackground` 才会绘制样式表背景；本轮已加，否则列表以外区域会露白。
- 单测 [tests/mark_panel_test.cpp](../tests/mark_panel_test.cpp)：100 条列表、点击/删除信号、`SelectMark`/`SelectNearFrame`、存储/回退/警告文案、空态、离屏性能。

### 2.2 MainWindow 接入

- 打开文件成功、旧文件 flush 后，用候选 `FrameIndex` 构造 `FrameLookup`：
  - `pts_of_frame` = `index.Entry(frame)->pts_us`；
  - `frame_of_pts` = `index.FindExactPts`；
  - `duration_us` = `MediaInfo.duration_us`；
  - 调 `MarkStore::Open`，失败/警告不阻塞画面。
- `Ctrl+M` → `AddMarkAtCurrentFrame`：默认标签、当前帧 PTS、立即 `Save`；保存失败弹提示但标记保留在会话内存。
- 点击侧栏 → `ActivateMark`：
  1. `Pause`、停拖动预览、选中行、播放头/帧号更新并 `repaint()`；
  2. `QTimer::singleShot(0)` 再 `GoToFrame` 精确解码。
  测量 UI p95 5.91ms、画面精确 p95 31.34ms（V9 1080p 短 GOP）。
- 删除必须经 `QMessageBox::question(Yes|No, 默认 No)`；确认后 `RemoveMark` + `Save`；自动化删除入口 `DeleteMarkForTest` 跳过对话框。
- `marks_dirty_` 跟踪未保存修改；切文件前 `FlushMarksBeforeSwitch`、关窗前 `FlushMarksOnClose`，失败弹“仍要打开/退出吗？”，不静默丢。
- 加载警告：面板警告条 + 状态栏首条；“更高 schema / 读失败”这类阻塞警告额外弹一次 `QMessageBox`；损坏备份、PTS 校正、迁移失败只用面板/状态栏，避免每次打开都弹框。
- 打开失败时保留旧 session 与旧标记；`OpenFile` 的 `CancelPendingMarkJump` 会取消未执行的标记跳转。
- `ShowEmptyState` 清空面板/时间轴标记/`marks_`，禁用 `Ctrl+M`。

### 2.3 时间轴标记

- [TimelineWidget](../src/app/TimelineWidget.h) 新增 `SetMarks(vector<int64_t>)`/`ClearMarks()`/`MarkFrameAtX()`。
- 只保存帧号；同帧多标记去重；绘制按帧排序，跳过不可见项，同一像素列只画一次。
- 粉色竖线（alpha 70）+ 顶部 3×8 小旗；在 A/B 色条之上、播放头之下。
- `mousePressEvent` 在 5px 内吸附到最近标记帧，仍走原 scrub 路径（按下暂停、松手精确）；A/B 标签不参与命中，避免和循环边界抢点击。
- 时间轴测试新增绘制像素断言、命中/吸附/清空断言；43.2 万帧 + 100 标记重绘 p95 0.286ms（fit）。

`main.cpp` 新增 `--mark-test`（配合 `--file A --file-b B`），设置 `LAPIAN_MARK_LOG`，按 §2 的序列跑 101 标记、重开、点击、20 次性能、删除、损坏 sidecar、F8-A3 隔离；截图写 `build/t5.2-marks-ui.png`、`build/t5.2-marks-warning.png`（已复制到 `docs/perf/`）。

## 6. 下一步 T5.3（备注编辑与自动保存）

目标（tasks.md T5.3）：侧栏编辑标签/备注、失焦或回车保存、允许为空、焦点隔离；验收 F8-A2，单测空备注/覆盖保存，关窗不丢。

建议：

1. **编辑形态**：选中标记后在侧栏底部加标签 `QLineEdit` + 备注 `QPlainTextEdit`（或 QTreeWidget 就地编辑备注列）。规格要求“失焦或回车即时保存”，多行备注需要明确 Enter 是保存还是换行；建议标签 Enter 保存，备注 `Ctrl+Enter` 保存、`Enter` 换行，文档里写清。
2. **保存**：编辑后调 `MarkStore::SetMarkText(id, label, note)`，置 `marks_dirty_`，可即时 `Save` 或 200–300ms 防抖；失焦/回车/切文件/关窗都要 flush。保存失败仍走 `ShowMarkSaveFailure`，不丢内存修改。
3. **列表刷新**：编辑时只更新当前行文本，避免每次按键重建 100 行；`SelectMark` 保持选中。
4. **焦点隔离**：`IsTextInputFocused` 已覆盖 QLineEdit/QTextEdit/QPlainTextEdit；但 `TogglePlayback`（Space）、`ToggleMute`、`ShowGotoDialog` 等全局 QAction 还没有统一让位，T5.3 要补，否则备注输入时按空格会播放。
5. **测试**：MarkPanel 加 `SetEditorTextForTest`/`CommitForTest` 或直接发 QKeyEvent；MainWindow 加 `SetMarkNoteForTest`、`CloseForTest`/`window.close()`，验证“编辑→关窗→重开→内容一致”；空备注保存后仍保留标记；删除最后标记删文件。
6. **不要改 schema**：`SetMarkText` 会更新 `updated_at`，沿用 T5.1 的 id+updated_at 合并；不要为了编辑新建 JSON 或 SQLite。
7. **F6-A1/A2**：T5.3 完成后补一次真人/自动化确认对话框路径；仍不要把长 GOP/正式 V1/基线机算通过。
