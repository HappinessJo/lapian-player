## 1. 一句话状态

**T3.1 音频解码与 WASAPI 代码完成；M3 进行中，下一步 T3.2（媒体时钟与同步）。**

现在应用可以：

- 打开带音轨的视频，正常播放时从第一条音轨出声；
- `M` 静音/取消静音，状态栏音量滑块调音量；
- 暂停、逐帧、跳帧时停止音频；再次播放时从当前帧 PTS 重新起播；
- 无音轨文件显示“无音频”，不创建音频引擎；
- 无输出设备/音频编码不支持时视频继续静音播放，状态栏提示；
- 设备失效（拔出/禁用）时释放并重建默认端点，播放中每 2s 重试，恢复后回到最后位置。

**还没有波形、循环/变速、标记/备注/截图/持久化；T3.2 的音频主时钟与 ≤1 帧同步尚未做。**

### 真实窗口行为

用 `LAPIAN_AUDIO_LOG=1` 记录：

- `--play` 启动后：`opening → 音频就绪 → playing`；V9 播放到末帧后 `已暂停`，进程保持运行。
- 按 `M`：`audio mute=1`；再按 `M`：`audio mute=0`。
- 播放中 `Space`：`已暂停`；再 `Space`：`audio start: target=0.708s`。
- 播放中两次 `PgDn`，再 `Space`：`已暂停` → `audio start: target=0.792s`。
- 中文路径 `media\测试.mp4`：音频解码器输出 `aac 48000 Hz 2 ch`，说明应用侧 UTF-8 路径正常。

## 4. 关键实现地图

| 文件 | 作用 |
|---|---|
| [src/audio/AudioFormat.*](../src/audio/AudioFormat.h) | 设备格式、`VolumeToGain`（平方律）、交错 float32 环形缓冲、float/PCM16 转换 |
| [src/audio/AudioDecoder.*](../src/audio/AudioDecoder.h) | 第一条音轨、独立 `AVFormatContext`、FFmpeg 解码、swresample 到设备格式、seek + 样本级裁剪 |
| [src/audio/WasapiRenderer.*](../src/audio/WasapiRenderer.h) | 默认 render endpoint、shared mode、event callback、`IAudioRenderClient`、`IAudioClock`（暂只保留）、设备失效检测 |
| [src/audio/AudioEngine.*](../src/audio/AudioEngine.h) | 音频工作线程、命令状态机、80/150ms 缓冲、音量/静音、2s 设备重试、状态上报 |
| [src/app/MainWindow.cpp](../src/app/MainWindow.cpp) | 打开时异步创建音频引擎、`M`/音量滑块、状态栏音频标签、播放/暂停/结束/跳帧联动 |
| [src/app/PlaybackController.h](../src/app/PlaybackController.h) | 暴露当前帧媒体秒，供音频起播 seek |
| [src/tools/audio_probe/main.cpp](../src/tools/audio_probe/main.cpp) | 控制台音频链路探针（设备格式/位置/underrun），不入分发 |
| [tests/audio_test.cpp](../tests/audio_test.cpp) | 音量/环形缓冲/格式转换 + V9 解码与 seek |

行为要点：

- 音频异步打开，首帧不等音频设备；状态每 200ms 轮询一次。
- `PlayFrom(当前帧 PTS)` 先 seek 到目标前 200ms，再丢弃目标前样本；预填约 30ms 后启动。
- 暂停/步进/拖动/跳帧通过 `PlaybackController::stateChanged(false)` 停声；恢复播放重新 seek。
- 软件增益：`gain=(volume/100)^2`，静音单独乘 0；不是 `ISimpleAudioVolume`。
- 设备失效：`AUDCLNT_E_DEVICE_INVALIDATED`/`AUDCLNT_E_RESOURCES_INVALIDATED` → 停流、释放、重开默认端点、seek 回最后位置；失败则静音继续视频。
- `LAPIAN_AUDIO_LOG=1` 输出设备格式、状态、start/seek、设备丢失/恢复、underrun 计数。

## 5. 环境与命令

```powershell
# 完整构建 + 测试 + 打包
powershell -ExecutionPolicy Bypass -File scripts\build-release.ps1

# 音频链路探针（ASCII 路径；不带 Qt）
.\build\release\bin\lapian_audio_probe.exe .\media\proxy\proxy-V1.mp4 10
.\build\release\bin\lapian_audio_probe.exe .\media\proxy\proxy-V1.mp4 2 --seek 5
.\build\release\bin\lapian_audio_probe.exe .\media\V9.mp4 2 --mute --volume 25

# 带诊断日志运行打包版
$env:LAPIAN_AUDIO_LOG='1'
.\dist\lapian.exe .\media\V9.mp4 --play
```

环境坑：

- `lapian_audio_probe` 用 `main(int, char**)` 接收参数；**中文路径经 cmd/PowerShell 传参可能变成系统代码页**，探针会打不开。应用本身用 `QString::toUtf8()`，中文路径已验证正常；探针测试请用 ASCII 路径或先复制。
- `ctest` 仍需 Qt bin 与工作区 TMP/TEMP；`build-release.ps1` 已处理。
- 新加 `.ps1` 必须 UTF-8 带 BOM（PowerShell 5.1）。

## 6. 已知缺口（不要误判为完成）

1. **设备拔出/禁用的物理手测未做。** 当前会话不是管理员，不擅自禁用系统音频；代码已实现失效检测、重建与 2s 重试，但“拔掉 USB 声卡/禁用端点后恢复”仍需真机验收。
2. **没有正式 V1/V7 素材。** 用的是 proxy-V1、V9 和本地生成的无音轨测试片；F1-A4 的波形区“无音频”仍要等 T3.5/T3.6。
3. **音画同步是近似。** 视频仍由 QPC 驱动，音频只是从当前帧 PTS 起播；T3.2 才用 `IAudioClock` 做主时钟并验 ≤1 帧。
4. **没有听感音量曲线验证。** 平方律由单测覆盖，实际响度需人耳。
5. **步进/拖动静音策略、淡入淡出、防爆音未做。** 属于 T3.7；当前只是暂停即停声，不能宣称 F3-A6/F5 静音完成。
6. **没有波形。** T3.5/T3.6 未开始。
7. **T2.4 帧缓存、T2.2 后台索引 worker 仍未做。** 与 T3.1 无关，但 P7/P2 正式验收前必须补。
8. **4K/基线机 p95 未做。** 现有音频数字是开发机单样本。
9. 音频设备默认端点切换（不拔出、只改默认设备）不会主动迁移；首期只处理失效重建，不承诺热切换。
10. `lapian_audio_probe` 是开发探针，不打包、不是用户功能。
