拉片软件 — 隐私、联网与数据位置说明
====================================

本说明适用于安装版和便携版。拉片软件不提供账号体系，不收集遥测/使用统计，
不检查自动更新，也不上传崩溃报告。

一、本地模式：不联网
--------------------
打开本地视频、播放、逐帧步进、波形、标记/备注、截图、设置和退出都不发起
网络请求。在线模块按需加载；没有输入 BV 号并确认在线打开之前，不会初始化
在线网络栈。

二、在线模式：只在明确操作后联网
--------------------------------
1. 输入 BV 号或 B 站视频链接并提交后，才访问 api.bilibili.com，用于读取公开
   元数据、播放地址、清晰度目录和登录状态（view/playurl/nav/quality 等接口）。
2. 只有点击“扫码登录”时，才访问 passport.bilibili.com 的官方二维码接口
   （generate/poll）；二维码在本地渲染，不加载远程图片。
3. 视频/音频数据从 playurl 返回的 B 站 CDN 地址下载。CDN 请求不携带
   SESSDATA/Cookie。
4. 不访问上述主机之外的地址；不把数据上传到本项目控制的服务器。
   网络请求由 Windows WinHTTP 发出，可能遵循系统代理设置。

三、在线缓存
------------
默认缓存根：%LOCALAPPDATA%\拉片软件\cache
默认配额：20 GiB（可在“设置 — 在线缓存”中修改）。缓存按 LRU 淘汰，可在设置
中查看占用、打开目录、清空缓存或清理孤儿条目。清空缓存不会删除在线标记/
备注/截图；当前会话的条目会保留。

缓存内容是 B 站视频/音频分片和元数据（标题、UP 主、BV/cid、清晰度等），
不包含 SESSDATA、Cookie 或签名 URL。缓存是普通本地文件，不做加密。

如果在设置中改了缓存目录，旧目录不会自动迁移或删除；卸载程序只清理默认
缓存目录，不会清理你自定义的缓存目录。

四、在线记录、截图与设置
------------------------
- 在线记录（标记/备注）：%APPDATA%\拉片软件\online\<bvid>-<cid>.lapian.json
- 设置：%APPDATA%\拉片软件\settings.json
- 截图：%USERPROFILE%\Pictures\拉片软件\<bvid>\；图片目录不可写时回退到
  %APPDATA%\拉片软件\online\snapshots
- 本地视频旁的标记/备注 sidecar：与视频同目录的 <视频名>.lapian.json
这些文件只保存在本机，不会被上传。

五、登录凭据
------------
登录是可选功能。只保存 SESSDATA 一项 Cookie，使用 Windows DPAPI（当前
Windows 用户）加密，默认位置：
%APPDATA%\拉片软件\credentials.dat

SESSDATA 只发送给 api.bilibili.com，不写入日志、缓存、截图或在线记录；
可在在线打开对话框或设置中清除。清除后按未登录处理。

六、卸载与清理
--------------
卸载只删除程序文件、快捷方式、开始菜单项和本软件注册的“打开方式”项。
默认保留：
- %APPDATA%\拉片软件（设置、在线记录、凭据、marks 回退）
- %USERPROFILE%\Pictures\拉片软件（截图）
- 视频旁的 sidecar 与 snapshots\
- %LOCALAPPDATA%\拉片软件\cache（在线缓存）

卸载时会询问是否“同时删除在线缓存”，默认选“否”。只有明确选“是”，或静默
卸载时显式传入 /CLEARCACHE，才会删除默认缓存目录
%LOCALAPPDATA%\拉片软件\cache。即使清理缓存，也不会删除上面的记录、截图、
设置、凭据、marks 或 sidecar。
